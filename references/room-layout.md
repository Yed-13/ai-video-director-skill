# 场景布局：让每个机位拍到的是同一个房间

同一场景要出两个以上机位时用。不做这一步，每张首帧里的房间都不一样，到视频里更改不回来。

## 1. 唯一布局 `LAYOUT`

每个场景只写一份，用**东南西北**写，不写"右后方""右墙"这类相对方位（换个机位意思就变了）。家具贴墙、平行于墙，尺寸写出来。

```
LAYOUT（次卧，3.2 × 3.6 米，北在上）
北墙：原木色书桌（1.2 米宽）贴墙居中，桌左端是机器人；书桌右边白色三层置物架。
西墙：推拉窗，白纱帘 + 灰蓝遮光帘；窗台一盆绿萝。
东墙：单人床，床头朝北；东北角推拉门衣柜。
南墙：房门，向内开。
书桌前一把灰色转椅，椅背搭校服外套。
```

布局同时写进 `blocking/<场景>.json` 的 `props`（`rect` = x, y, 宽, 深），机位图、视野清单、白膜都从这一份算。

## 2. 每个机位的视野 `VIEW[机位]`

```bash
python3 scripts/view_list.py blocking/<场景>.json            # 全部机位
python3 scripts/view_list.py blocking/<场景>.json --camera s02
```

输出每个机位里每件家具、每个人、每面墙：在不在画面里，在画面横向哪里（-1 左 … +1 右），多远。整理成一段写进这个机位的首帧提示词和视频提示词：

```
VIEW[s02 过肩]：画面右侧前景是她的右肩和后脑（虚焦）；中间是书桌和正对镜头的机器人；
画面左侧是西墙的窗和纱帘；置物架、床、衣柜、门都在画外，不出现。
```

画外的东西一律不写进这个机位的画面描述：写了就会被画出来。

## 3. 俯视图只约束布局

每个机位另出一张俯视图 `plan_<机位>.png`（`floorplan.py` 的图上只留这一个机位），和首帧参考一起传给画图的一方，用途写"只用来确定家具位置和机位方向，不参考它的线条和颜色"。

## 4. 参考图的规矩

- **成片里已经对的画面，截下来当后续镜头的房间样板**，比重新画一张可靠。截图先擦掉平台角标。
- 新机位优先选已经拍过的方向。必须拍反打或背面时，先确认参考图和已拍画面一致；不一致就以成片截图为参考重画，再和已拍画面逐件对照。
- 两张参考图互相矛盾（一张有床、一张没有）时去掉一张，模型不会替你取舍。
- 参考图里的状态和本段不同时写明："图里屏幕亮着，本段屏幕熄灭"。
- 构图参考图里的人物姿势会被照搬。用途写"只参考机位、构图和房间，人物动作以文字为准"，姿势差得远就先把图改对。

## 5. 道具连续性清单

容易跑位的道具（外套、杯子、书包、纸）列进 `shotlist.md` 末尾的清单：在哪、什么状态、从哪一镜起变。首帧出齐后逐张核对，不对就只改这一处（Pillow 贴回，见 `04-keyframes.md`）。
