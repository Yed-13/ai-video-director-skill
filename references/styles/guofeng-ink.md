# 风格：国风、水墨

水墨靠留白和墨的浓淡，动得越少越像。这一类公开资料最少。

## 画风句模板

图片用：
```
中国传统水墨画：宣纸底色微微泛黄，大面积留白；墨分浓淡干湿，远山是淡墨晕染，
近处的<松枝>用浓墨枯笔；只有<一点朱红>是彩色；虚实结合，雾气把中景隐去；
像装裱前的一张画，不是照片，不是 3D 渲染，没有高饱和色。
```
工笔、青绿山水、新国风插画各换一套描述，不和水墨叠加：
```
新国风工笔插画：细而匀的墨线勾边，矿物色平涂（石青、石绿、赭石），绢本质感，无透视变形。
```
视频用（放最后）：`水墨质感全程保持，墨色只有浓淡变化；动作轻而慢。不是写实，不是 3D，没有高饱和色。`

## 首帧

- 先出一张水墨静帧当首帧，画风完全靠它；文生视频出水墨最容易跑成照片加滤镜。
- 留白要大。画面填满，模型会把空白处补上东西。
- 人物小、在景里；大特写的水墨人脸最难保持。

## 动作和运镜

- 只写轻动作：雾飘、水流、衣袖和柳枝摆动、鸟飞过、墨慢慢晕开。片段 5–8 秒。
- 墨的变化按时间顺序写：`一滴墨落在宣纸上 → 慢慢晕开成远山的轮廓 → 山脚显出一叶小舟`。
- 运镜像展开卷轴：固定机位，或沿画面缓慢横移；不想动就明写"固定镜头"。不用环绕和大幅推进：一有透视变化就露出 3D。
- 图生视频只写运动和运镜，不重复画面内容。

## 特有的失败（未实测，按通用规则推断）

| 现象 | 改法 |
|---|---|
| 变成照片加滤镜、或 3D | 首帧重做；删写实词；结尾加负面小句 |
| 墨到处乱飘、画面"活"过头 | 写明只有哪一样在动，其余"像画在纸上一样不动"；缩短片段 |
| 留白被补上东西 | 写"上半部分是空白的宣纸，始终空着" |
| 颜色越来越多 | 写明唯一的彩色是什么，其余只有墨色 |
| 题字、印章变乱码 | 首帧不画字和印，后期贴真实的 |

## 示例

```
@图片1 作为首帧。固定镜头。远山和松树像画在纸上一样不动；
只有山腰的雾从画面左侧缓慢飘向右侧，江面有极轻的水纹；一只白鹭从右下角飞起，斜着飞出画面上方。
水墨质感全程保持，墨色只有浓淡变化。不是写实，不是 3D，没有高饱和色。
```
