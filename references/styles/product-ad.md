# 风格：产品广告

产品是不能变的那个东西。提示词写镜头和光，不重复描述产品（图里有）；每条都带一句"产品锁定"。可以和写实、3D 等画风组合：画风按对应文件，这里只讲产品片特有的。

## 先写这一段要证明什么

一句话："观众看完，要相信这是一个真实存在、能自然回应人的桌面机器人。" 然后删掉和它无关的动作。一个准确的小动作，比一串大动作有说服力。

- 一个镜头一个任务：在哪 → 是什么 → 做一件事 → 人的反应 → 一个细节 → 收尾留白。
- **不拍产品做不到的事。** 没有的关节、没有的功能、不存在的声音都不加；概念片不当实机演示发布。
- 普通镜头 4–6 秒；可以多生成一点剪出稳的部分。整条广告不要一次生成：产品会变形。

## 素材

- 产品图：干净的白底或渐变底，正面、侧面、三分之四，加局部。实拍优先。
- 环境图：真实的桌面、窗光。
- 标志、文字、屏幕界面：单独的透明图，后期合成。不让模型生成字和品牌。
- 首帧里给一个尺寸参照物（书、杯子），并让底座和桌面有清楚的接触阴影。

## 产品锁定句

每条视频提示词都带，按产品改：
```
产品是刚性的实物：外壳轮廓、屏幕比例、接口位置和各部分比例整个镜头保持一致；底座始终稳稳接触桌面。
```

## 镜头写法

| 镜头 | 写法 |
|---|---|
| 外观 | `产品静止在桌面原位。摄影机沿直线缓慢靠近，从中景停在中近景，高度不变。表面反光随视角轻微变化。` |
| 细节 | `外壳接缝和屏幕边框的近景，摄影机向右移动一小段。接缝保持清楚，磨砂表面的反光轻微变化。` |
| 小弧线 | `产品静止。摄影机沿短弧线从正前方移到右前侧三分之四视角，始终看向产品中心，然后停住。` |
| 一个功能 | `固定机位。一只手从画面右侧进入，食指轻按按钮，停一下，收回。按下之后屏幕才慢慢亮起。` |
| 揭示 | `从产品近景沿直线缓慢后退，露出桌面和坐在旁边的人。产品留在原位。` |
| 收尾 | `产品静静停在桌上，固定机位。屏幕表情变化一次后保持不动，最后两秒画面安静稳定。`（一侧留出放品牌字的空位） |

- 只有正面图时不做完整环绕：背面是模型编的。
- 推进变成变焦式形变时，改固定机位，后期小幅裁切代替。
- 屏幕内容漂移：换成均匀的暗色屏幕，后期跟踪合成界面。
- 高运动强度是产品片的常见错误：摄影机和产品同时大动，产品必变形。
- 运镜词表见 `camera-moves.md`。

## 抽卡

产品镜头对形状零容忍，每镜抽 5–10 条（`gacha.md`）。

## 收片重点查

外壳轮廓首中尾三帧对比；接口和按钮位置；底座有没有滑动或浮起；手和产品的接触点是否同步；反光方向和光源是否一致；有没有多出来的零件。

## 声音

环境底噪加和动作对应的拟音（按键、放下）。产品本身没有的声音不加。音乐只管节奏。品牌文字在产品造型、颜色、屏幕都检查完以后再加。
