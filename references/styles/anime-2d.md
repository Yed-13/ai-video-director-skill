# 风格：2D 动画（日式赛璐璐、平涂手绘）

模型的默认倾向是写实和 3D。2D 片的工作是一直把它按在平面上：首帧定画风，线粗色少，动作有"顿"。

## 画风句模板

图片用：
```
日式 2D 赛璐璐动画的一格画面：干净利落的黑色描线，线条粗细一致；平涂上色，
每个色块只有一层硬边阴影，没有渐变；色板限定为<藏青、米白、砖红、浅灰>；
背景是手绘水彩质感，比人物简单；像电视动画的正片截图，不是插画海报，不是 3D 渲染。
```
视频用（放在提示词最后）：
```
2D 手绘动画，赛璐璐平涂，硬边阴影，线条稳定。动作是有节奏的关键姿势加停顿，不是匀速滑动。
不是 3D 渲染，没有渐变、柔和阴影和体积光。
```

- 点名具体颜色能锁住色板。
- 不写的词：cinematic lighting、4K、超清、电影感、真实皮肤、glossy。它们会带来体积光和 3D 质感。
- 想要别的 2D 味道就整句换掉，不叠加：平涂矢量、绘本水彩、粗线美式卡通各写各的一套。

## 设定图和首帧

- 身份板照 `03-style-sheets.md` 做，另加：表情特写多给几个（动画靠表情讲故事），标明线色和阴影层数。
- 线越细、细节越多，动起来越容易"沸腾"。头发分成大色块，不画发丝；衣服花纹能省就省。
- 背景简单、和人物明度拉开：复杂背景更容易闪。
- 首帧阴影只留一层硬边，提示词里不写 soft shading（未实测：防止阴影融化）。
- 先单独出一张干净的静帧，确认是想要的画风，再做视频。

## 表演和运镜

和写实相反，动画要夸张、要有预备动作和停顿：

- 写关键姿势和停顿：`她先缩一下肩（预备），猛地回头，头发甩过去后停住，定格半秒`。
- 一个镜头一个主动作，加一个次要动作（头发、围巾、衣角飘一下）就够。
- 镜头短：2–4 秒一个镜头，靠剪辑给节奏；难画的动作用剪辑绕开。
- 运镜用动画的惯例：固定机位为主；推拉写"缓慢推近"；横向写"背景向左平移"；少用环绕和真 3D 透视变化（最容易变成 3D）。
- 首帧 + 尾帧让模型补中间，比只给首帧稳。
- "一拍二 / 一拍三"、速度线这类术语模型是否听懂没有可靠资料（未实测）。要低帧率的手绘感，后期把画面降到 12 fps 再回到 24 fps 更可靠：`fps=12,fps=24`。

## 特有的失败

| 现象 | 改法 |
|---|---|
| 变成 3D 或半写实 | 首帧重做得更平；删掉写实词；结尾加"不是 3D 渲染" |
| 线条沸腾、抖动 | 线加粗、细节减少；动作幅度减小；片段缩短 |
| 色块边缘爬行、闪烁 | 色板减少；相邻色块明度拉开；背景简化 |
| 运动太顺，没有动画的"顿" | 写关键姿势加定格；后期降帧 |
| 转头时脸变形 | 转头幅度减小；拆成转头前、转头后两个镜头硬切 |
| 手和肢体融化 | 手势简单；手不做精细动作；出画或被挡住 |
| 头发衣服飘得停不下来 | 写"飘一下后落回原位，之后不动" |
| 嘴型乱动 | 不说话的写"嘴闭着"；说话镜头用远景、背影或后期配音配字幕 |

## 示例

首帧已是天台上的女孩，背对夕阳：
```
@图片1 作为首帧。她站着不动，风把头发和围巾吹向画面右侧，飘一下后落回。
她先低一下头（停半拍），然后回头看向画面左侧镜头外，眼睛睁大，定住。
固定机位，中近景，缓慢推近一点。背景的云几乎不动。
2D 手绘动画，赛璐璐平涂，硬边阴影，线条稳定。动作是关键姿势加停顿。不是 3D 渲染，没有渐变和体积光。
```

长一点的动漫短剧见 `manju.md`。
