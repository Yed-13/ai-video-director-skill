# 按风格分类

开工时和用户定一种主风格，记进 `brief.md`，之后只读对应的那一份。一支片子只用一种主风格：混着写会被模型平均成一团。

| 风格 | 读 | 一句话 |
|---|---|---|
| 写实实拍（剧情片、纪录感、宣传片） | `realistic.md` | 外观交给参考图，动作少而具体，摄影有理由 |
| 2D 动画（日式赛璐璐、平涂手绘） | `anime-2d.md` | 首帧定画风，线粗色少，动作要有"顿" |
| 国风、水墨 | `guofeng-ink.md` | 留白、轻动作、短片段，墨的变化按顺序写 |
| 3D 卡通（动画电影式） | `cartoon-3d.md` | 圆润造型、柔和光，每镜同一段风格句 |
| 定格、黏土 | `stop-motion.md` | 材质上的手工痕迹 + 低帧率的跳动感 |
| 产品广告 | `product-ad.md` | 产品锁定，只写镜头和光，字后期加 |
| 漫剧（竖屏动漫短剧） | `manju.md` | 资产先锁死，一集一个冲突，逐镜可返工 |

没列出的风格（像素、剪纸、油画、赛博朋克等）：按最接近的一类走，把下面的通用规则用上，新发现记进 `lessons.md`。

## 各风格通用的规则

1. **首帧比提示词更决定画风。** 风格先在图上做对，再让它动。视频提示词写不出首帧里没有的风格。
2. **风格锚点句每镜原样复制**（`brief.md` 里的固定画风句）。换一个近义词，镜头之间就开始漂。
3. **写实词和风格词不混用。** 非写实片里不写 cinematic lighting、4K、photoreal、超真实、电影感：它们会把画面拉回写实或 3D。
4. 每段一个主动作、一种运镜，片段短，多出几条挑（`gacha.md`）。
5. 负面约束只在结尾写一小句，针对这个风格最常见的跑偏（2D 写"不是 3D 渲染，没有渐变和柔和阴影"）。其余都用正面写法。
6. 文字、标志、界面一律后期加。
7. 光色表照样做（`light-color.md`）。动画的光可以不讲物理来源，但同一场戏的色板要一致。

## 可信度

写实一份在真实项目上用过。其余几份来自第三方教程和论坛，没有对照实验；标"未实测"的是推断。先小样验证，结果记进 `lessons.md`。
