# 风格：定格、黏土

定格的味道来自两样：材质上的手工痕迹，和低帧率的跳动感。模型两样都想抹平。

## 画风句模板

图片用：
```
定格动画的一格：角色是软陶黏土捏的，表面看得见指纹和工具压痕，哑光不反光，
接缝和关节处的连接看得出来；布景是手工搭的微缩场景，纸板、毛毡和木头；
一盏台灯从左上方打来的硬光，阴影清楚；微距镜头的浅景深；不是 CG，不是光滑的 3D 渲染。
```
毛毡、纸艺、积木各换材质词：毛毡写"羊毛毡的绒毛边缘"，纸艺写"卡纸的切口和折痕"。

视频用（放最后）：
```
定格动画质感：约 12 帧的跳动感，每个姿势停住再换下一个，不是平滑插值，没有运动模糊。
黏土表面哑光，有指纹。不是写实，不是光滑的 CG。
```

## 首帧

- 材质要在首帧里看得见：指纹、压痕、接缝。首帧光滑，视频里不会长出手工感。
- 灯光像桌面拍摄：一两盏实用灯、硬阴影，不用柔和的大面积布光。
- 微缩感靠浅景深和略俯的机位。

## 动作和运镜

- 把动作拆成几个停住的姿势：`起始 → 中间 → 到位`，每个姿势"停住"。
- 动作简单：歪头、挥手、跳一下、走两步。
- 机位固定为主，像架在三脚架上逐格拍；要动就写"缓慢地横向漂移一点"。
- 生成的片子通常还是太顺：后期降帧是标准做法，`fps=12,fps=24`（先抽到 12 帧，再回到 24 帧容器）；想更卡用 8。

## 特有的失败

| 现象 | 改法 |
|---|---|
| 运动太顺，像 3D 动画 | 提示词加帧率和"姿势停住"；后期降帧 |
| 表面发亮、像 CG | 写"哑光"；写出接缝和连接处；灯光改硬光 |
| 有运动模糊 | 写"没有运动模糊，每一格都清楚" |
| 指纹和纹理每帧乱变 | 降低纹理强度；动作幅度减小 |
| 角色越动越光滑 | 片段缩短；每段都从带纹理的首帧开始 |

## 示例

```
@图片1 作为首帧。黏土小兔在桌面布景上：先歪一下头，停住；再抬起右前爪，停住；挥两下，放下。
固定机位，略俯的中景。台灯的硬光方向不变。
定格动画质感：约 12 帧的跳动感，每个姿势停住再换下一个，没有运动模糊。黏土表面哑光，有指纹。不是光滑的 CG。
```
