# 风格：写实实拍

"更真实"不是一个形容词，把 realistic 换成 ultra realistic 没用。拆成三件事：外观交给参考图；动作少而具体；摄影有理由。写实不等于粗糙，也不等于手持：三脚架、干净的商业布光都是真实摄影，随手加抖动、颗粒、污渍不会更真。

## 四种"AI 味"，分开治

| 类型 | 看到什么 | 先改哪里 |
|---|---|---|
| 静态外观假 | 塑料皮肤、材质太亮、所有东西都是新的 | 参考图和首帧 |
| 动作假 | 漂浮、滑步、手和杯子粘连、物体没重量 | 动作设计、接触关系、拆镜头 |
| 时间上不稳 | 脸变了、外壳变形、背景物件消失 | 输入一致性、动作复杂度、选片 |
| 摄影味不对 | 无理由环绕、处处光晕、全程慢动作 | 运镜、光、景深、剪辑 |

## 画风句模板

图片用：
```
真实电视剧剧照，像用 35mm 电影胶片拍的<家庭剧>：皮肤有真实毛孔、细纹和一点油光，不磨皮；
布料有褶皱和起球，物体有重量和接触阴影；可见的胶片颗粒，轻微高光溢出；色调<温暖>、饱和度略低，
暗部保留细节；构图不刻意对称，杂物摆放随意。
```
视频用（接在上面后面）：`24 帧，自然的运动模糊，焦外柔和；镜头里的人像没有意识到摄影机存在。`

干净的产品或商业片把"胶片、颗粒、杂物随意"换成"自然商业摄影，曝光克制，白色保持中性"。先选拍摄类型（家庭剧 / 纪录式 / 商业广告 / 手机记录），再定颜色和镜头感。

## 参考包

- 主体：正面、侧面、三分之四，必要时背面和局部。有实物就拍实物；CAD 或渲染图只约束结构，不能直接当写实首帧。
- 环境：一张看得清窗、桌、家具位置的全景。自己拍的真实房间和材质照片，比继续堆质感词有用。
- 人物：同一人、同一服装的清晰照片或确认过的角色图。平台拦截写实人脸上传时，用生成的身份板。
- 屏幕、界面、标志：单独准备，后期合成。
- **每张参考图写明分工**："图 1 定机器人外观；图 2 定房间布局；图 3 只参考光线和色彩，不采用其中的人物和家具。"

检查参考图：主体有没有被裁、有没有广角拉伸和过度磨皮、材质分不分得清、手是否真的握住物体、不同照片是不是同一版本、有没有被镜像。

## 首帧：暂停时也可信

静帧像游戏宣传图，动起来不会变成实拍。顺序：外形准 → 光影和环境一致 → 材质不全是抛光塑料 → 接触处有阴影 → 皮肤保留自然起伏（不是加满毛孔）→ 背景有适度生活痕迹。

多机位的房间布局见 `room-layout.md`。

## 视频：只写变化

只写变化、不写图里没有的东西，规则见 `06-video-prompt.md` 第 1 节。写实片另外注意：

- 先试最短有效版本，结果明确缺什么再补对应约束：
  `机器人缓慢向右侧的人转头，停下后保持姿态。底座始终稳稳接触桌面。固定机位，正常速度，外壳和屏幕形状保持一致。`
- 写物理，不写"自然"：`手指先围住杯柄，握稳后把杯子缓慢提离桌面。杯子保持竖直，手腕承托重量，停在胸前，杯里的水只轻轻晃一下。`
- 每个动作写开始、变化、停止状态。
- 正面写法代替负面清单：

| 不够清楚 | 改成 |
|---|---|
| 不要乱动 | 底座固定，只有头部缓慢转动 |
| 不要 AI 皮肤 | 皮肤保留细微纹理和柔和的明暗变化 |
| 不要乱变 | 屏幕边框和外壳轮廓整个镜头保持一致 |
| 不要诡异笑容 | 嘴角轻微上扬，随后保持放松 |
| 不要过曝 | 窗边高光柔和，亮部仍有纹理 |

- 平台的"自动增强提示词"先关掉，或先看它改成了什么：它会悄悄加慢动作、戏剧光和华丽运镜。
- 不拍产品做不到的事：没有转头机构就不写转头，改成屏幕上的眼睛图案移动。

表演和台词见 `acting-voice.md`；运镜见 `camera-moves.md`。

失败怎么改见 `07-review-repair.md` 的"问题 → 先判断 → 优先尝试"表。

## 给新模型做基准：三条练习片

换模型或换版本时，用同一张首帧出三条，分开判断问题来自哪里：A 主体不动、摄影机轻推；B 摄影机不动、主体做一个小动作；C 都不动、只有屏幕或环境变化。同素材每条出 2–3 次，只记"可用 / 不可用、主要问题"。
