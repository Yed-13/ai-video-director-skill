# 风格：漫剧（竖屏动漫短剧）

用动画画风做的连续短剧，多为 9:16。画风按 `anime-2d.md` 或 `cartoon-3d.md`，这里只讲成系列生产的做法。各家的数字不一，下面给的是起点。

## 一集的规格

- 画幅 9:16；一集 60–90 秒，一个主冲突，开头 3 秒出冲突，结尾停在悬念上。
- 两种切法，按台词密度选：
  - **短镜头**：8–12 个镜头，每个 3–5 秒，逐镜生成。动作多、节奏快的戏。
  - **按场多镜**：5 段左右，每段 10–15 秒、2–4 个镜头一次生成（Seedance 2.5 单段可到 30 秒）。对话戏，场内一致性更好。
- 返工只重拍坏的那一镜或那一段，所以每段都要能独立替换：段与段之间用硬切，不依赖跨段的连续动作。

## 资产先锁死

系列片最怕第三集的主角和第一集不像。开拍前做齐，之后只引用、不重画：

- **角色**：三视图（正、侧、背）+ 3–5 个表情 + 常用姿势，做成身份板。每个角色一张，文件名带版本号，换装另做一张。
- **场景**：每个常用场景一张无人的全景，对话戏加正打、反打（`03-style-sheets.md`）。
- **固定句**：画风句、每个角色的人物卡、每个角色的声音描述，写进 `brief.md`，每集原样复制。
- 资产放在系列共用的文件夹，每集的项目只引用。

## 竖屏的镜头

- 竖屏装不下横向的两人中景：对话用单人镜头交替（内反拍），或一前一后的纵深构图。
- 人物占画面高度的一半以上；脸放在上三分之一。
- 下方四分之一留给字幕和平台按钮，重要的东西不放那里。
- 情绪点给大特写；每 2–3 个镜头换一次景别。

## 台词和口型

- 台词三种写法照旧分开：当面说、内心独白、画外音（`06-video-prompt.md`）。漫剧里内心独白多，独白时写"嘴闭着"。
- 模型直接出的对白和口型，有人说能用，有人说不稳。先拿一段测。不稳就走另一条路：画面里只写"嘴部轻微开合"或干脆不拍嘴，后期统一配音、加字幕。
- 2D 动画的口型本来就简化，观众容忍度比写实高；但声音要同一个人：第一集定下的声音剪出来当后面每集的音频参考。

## 时间标注

动作节奏可以按整数秒写（Seedance 2.5 支持）：
```
0-3 秒：她推开门，愣在门口。
3-6 秒：切到近景，他慢慢转过身。
6-10 秒：切回她的特写，她后退半步，说：「……怎么是你？」
```
区间首尾相接，不留空；每个区间里的事不要太少（模型会自己加戏）也不要太多（会多切镜或漏情节）。对白本身不标秒。

流程和总流程相同，只是资产和固定句跨集复用；每集新出现的资产和好用的写法记进系列的 `lessons.md`。
