# 风格：3D 卡通（动画电影式）

离模型的默认倾向最近，最容易出片；3D 的柔和渐变和阴影还能盖住闪烁。主要风险是往写实漂、角色在镜头之间变样。

## 画风句模板

图片用：
```
风格化的 3D 动画电影画面：圆润的角色造型，头身比<约 3 头身>，大眼睛，简化的五官；
皮肤有柔和的次表面散射，布料和毛发是简化过的材质；暖色主光加柔和轮廓光；
背景是同一风格的简化场景；动画长片的成片质感，不是写实，不是玩具摄影。
```
视频用（放最后）：`风格化 3D 动画，圆润造型，柔和光线，全程同一画风；表演夸张而清楚。不是写实真人。`

不借用具体公司或作品的名字来定风格，写特征。

## 设定图和首帧

- 身份板必做，角色漂移全靠它压：每个镜头都喂同一张身份板，不换版本。
- 头身比、眼睛大小、手指数量（很多卡通角色是四指）写死进人物卡。
- 材质定一档"简化程度"：毛发是一片片的大簇还是逐根，全片一致。

## 表演和运镜

- 表演可以夸张：先预备再动作，表情大而清楚，动作做完有回弹（挤压和拉伸）。
- 一个镜头一个主动作：`他眨一下眼，然后抬头，露出一个浅笑。`
- 运镜轻柔：缓慢推近、小幅横移、跟随。真 3D 运镜在这个风格里是安全的，但仍然一镜一种。
- 可以配合白膜（`05-greybox.md`）：这个风格和白膜最合得来，官方也有"3D 白模转动画"的用法。

## 特有的失败

| 现象 | 改法 |
|---|---|
| 往写实漂（皮肤出毛孔、布料出织纹） | 各镜头的画风句一字不差；删掉 4K、超清、真实一类词 |
| 角色在镜头之间变样 | 每镜同一张身份板；人物卡原样复制 |
| 像塑料玩具 | 写"柔和的次表面散射，不是塑料反光"；光改成侧前光加轮廓光 |
| 表演像真人一样克制、平淡 | 写预备动作、夸张的表情变化和回弹 |
| 眼睛发光、表情过激 | 情绪词太猛；换成具体的肌肉和动作描述 |
