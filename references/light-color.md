# 光影与色彩

模型看不懂"电影感""高级感"，看得懂：光源是什么、从哪边来、硬还是软、冷还是暖、亮还是暗；画面什么颜色、反差多强、饱和多高。阶段 2 定光色表，阶段 3–6 照着画和写，阶段 7–8 用 `look.py` 检查和统一。

## 1. 光色表：一场戏锁一套光

同一场戏所有段落的光源方向、冷暖、时间、色调完全一致，否则剪在一起像两部片子。`palette.md` 每场戏一节：

```markdown
## 场 2：书院庭院（外，日）
时间 / 天气：午后，晴
主光：太阳，画面左上方侧前光，硬光，暖白（约 4500K）
辅光 / 环境光：天空反射，偏冷，弱；光比约 4:1
实用光源：无
色调：暖金 + 青灰互补，中等饱和；强调色：主角的红发带（只有它是饱和红）
影调：中高反差，暗部有层次不压死
色值：主 #D9A15B　辅 #6E8A8F　暗部 #2F3A3D　强调 #C2352B
中文光色句：午后左上方的暖白硬光从侧前方照亮人物，阴影偏青灰，中等饱和，暗部有层次。
英文光色句：Hard warm-white afternoon sunlight from the upper left lights the subjects from the front-side; shadows lean cool teal-grey; medium saturation with detailed shadows.
```

- 每段的图片和视频提示词**原样复制**这场戏的光色句。
- 设定图统一用中性的三点布光，不带场景光色。
- 色彩剧本：每场戏用 `look.py swatch` 画一条色块，按时间排在一起，看全片冷暖和明暗的节奏；相邻两场在冷暖或明暗上拉开。颜色可以跟着情绪走（疏远时冷、和解时暖），强调色只给关键的人或物。

## 2. 设计时的要点

- **色温**：越低越暖。烛光约 1900K、钨丝灯约 3000K、黄金时刻约 3500–4500K、正午约 5500K、阴天约 6500–7500K、背阴处和蓝调时刻 8000K 以上。
- **冷暖对比**最好用：室内暖灯 + 窗外冷蓝；夜景冷蓝环境光 + 暖色窗户和路灯。每种颜色的光，画面里都要有说得通的光源（窗、灯、屏幕、火）。
- **色偏**：荧光灯、旧路灯偏绿。皮肤偏绿、偏紫、偏橙最容易让人出戏，无论什么风格都先保肤色。
- **方向**：顺光平、显假；侧前光（约 45°）立体，最常用；加一点轮廓光把人和背景分开；侧光、顶光、底光用于冲突、压抑、恐怖。最简单的提升：顺光改侧前光，再加轮廓光。
- **软硬**：硬光（正午、裸灯）紧张、真实；软光（阴天、纱帘窗光）温柔、显皮肤好。
- **光比与调子**：约 2:1 是高调（明亮、轻松），约 4:1 有立体感，8:1 以上是低调（悬疑、夜戏）。夜戏暗部要有层次，不能一片死黑。
- **影调**：黑位压死显得浓重，提黑（灰雾）显得像胶片、复古；高光柔和过渡是胶片感，死白是数码感。

常用风格配方（色调 / 影调 / 质感）：

| 风格 | 配方 |
|---|---|
| 青橙 | 肤色和高光偏暖橙，阴影偏青；中高反差；别让肤色发橙 |
| 暖黄怀旧 | 偏暖黄、略低饱和；提黑、低反差；颗粒 |
| 冷蓝悬疑 | 偏冷蓝青、低饱和；低调、高反差；只留一个暖色实用光源 |
| 日系清新 | 略偏青、低饱和；高调、低反差、略过曝；软光 |
| 胶片 | 暗部略偏青绿、高光偏暖；提黑、高光柔和；颗粒、轻微光晕 |
| 黑色电影 | 黑白或极低饱和；低调、强反差、硬光；百叶窗影子、烟 |
| 赛博朋克 | 洋红和青的霓虹；低调；湿地面倒影、雾 |
| 莫兰迪 | 带灰的低饱和色；低反差 |

## 3. 写进提示词

每个镜头写全：运镜、景别、角度、主体（谁、什么神情）、运动（动多少）、**光影（光源、方向、软硬、冷暖、明暗）**、焦段和景深，最后接光色句。

```
固定镜头，面部特写，平视，女孩低头看着手里的信，几乎不动，只有睫毛轻颤；
画面左侧窗外低角度的暖金色夕阳侧逆光，硬光，在左脸和发丝上勾出亮边，右脸在柔和的冷蓝阴影里；
85mm，浅景深，背景虚化；<光色句>
```

1. 写具体的光源和方向，不写形容词。
2. 色温数字配颜色词（"约 3200K 的暖橙色钨丝灯光"）；模型对纯数字的反应不一定可靠，第一次用时对比一下。
3. 光必须和首尾帧一致，视频提示词不另外发明光。
4. 一个镜头里不换光；必须换（开灯）时写明原因和时间点，首尾帧画出前后两种状态。
5. 浅景深可以掩盖背景里的瑕疵，对话镜头多用。体积光、镜头光晕一场戏最多一两次。颗粒、暗角、光晕在后期统一加，提示词里不写。
6. H3 用具体的英文：`warm low-angle sunset light from frame left rims her hair; the right side of her face falls into soft cool-blue shadow; shallow depth of field, 85mm`。

## 4. 检查与统一：`look.py`

```bash
python3 scripts/look.py analyze shots/s03/first.png shots/s03/takes/s03_take1.mp4
python3 scripts/look.py compare <这场戏的基准帧> shots/s0*/takes/*_take1.mp4
python3 scripts/look.py swatch "#D9A15B" "#6E8A8F" "#2F3A3D" -o palette_scene2.png
```

- `analyze`：亮度、反差、黑白位、饱和度、等效色温、绿—洋红色偏（Duv，±6‰ 以上可见）、主要颜色、一句话总结；视频抽 5 帧，并提示内部漂移。
- `compare`：以第一个文件为基准，标出偏暖 / 偏冷 / 偏亮 / 偏暗 / 饱和度 / 色偏，给出 ffmpeg 校正参数。调完再量一次，人眼确认肤色。
- 等效色温反映的是画面整体的冷暖倾向，满屏有色物体时不准。只用来比较同一场戏的镜头，不当绝对值。

ffmpeg 调色积木。顺序：先校正，每个镜头调到和基准一致；再风格化，全片同一套参数；最后加质感。

```bash
colortemperature=temperature=5600:pl=1:mix=0.6     # 低于 6500 变暖，高于变冷；pl=1 保持亮度
colorchannelmixer=gg=0.95                           # gg<1 去绿，>1 去洋红
colorbalance=rs=-0.05:bs=0.06:rh=0.06:bh=-0.04      # 暗部偏青、高光偏暖
eq=contrast=1.08:brightness=0.01:saturation=0.9
curves=master='0/0.06 0.5/0.5 1/1'                  # 提黑
vibrance=intensity=0.15                             # 只提不饱和的颜色，保护肤色
lut3d=file=look.cube
noise=alls=6:allf=t,vignette=PI/5                   # 颗粒和暗角，放最后
```
