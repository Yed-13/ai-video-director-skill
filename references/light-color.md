# 光影与色彩

AI 看不懂"电影感""高级感"。它看得懂的是：**光从哪边来、硬还是软、冷还是暖、亮还是暗，画面是什么颜色、对比多强、饱和度多高**。这一章讲怎么把这些设计好、写具体，并且在几十个镜头之间保持一致。

使用时机：

- 阶段 2 定配色时，同时定每场戏的**光色表**（第 8 节）；
- 阶段 3 画样帧时，按光色表出图；
- 阶段 4、6 写图片和视频提示词时，从光色表原样复制光色描述；
- 阶段 7、8 用 `scripts/look.py` 检查各镜头的颜色是否一致，并在后期统一。

---

## 1. 色温

色温用开尔文（K）表示光源的颜色。**数值越低越暖（橙红），越高越冷（蓝）**，和日常说的"温度高 = 暖"正好相反。

| 光源 / 环境 | 大约色温 | 画面感觉 |
|---|---|---|
| 火柴、烛光、篝火 | 1700–1900K | 很暖的橙红，亲密、怀旧、危险 |
| 日出日落时的太阳 | 2000–3500K | 金橙色，长影子 |
| 家用暖白灯泡、钨丝灯 | 2700–3200K | 温馨、室内夜晚 |
| 黄金时刻（日出后、日落前约一小时） | 约 3500–4500K | 暖金色，柔和，人物好看 |
| 冷白荧光灯、办公室 | 4000–5000K | 偏中性，常带一点绿 |
| 正午阳光 | 5000–5600K | 中性白，硬光，高反差 |
| 阴天 | 6000–7500K | 偏冷，柔和，低反差 |
| 背阴处（晴天的阴影里） | 7000–8000K | 明显偏蓝 |
| 蓝调时刻（日落后二三十分钟）、晴朗的蓝天 | 9000–12000K 以上 | 深蓝，安静、忧郁 |
| 霓虹、彩色 LED | 不适用（是彩色光） | 洋红、青、紫等饱和色，都市夜景 |

### 白平衡与"创意白平衡"

- 摄影机的白平衡决定"把哪种光当成白色"。白平衡设成日光（5600K）去拍钨丝灯，画面会偏橙；设成钨丝灯（3200K）去拍日光，画面会偏蓝。
- 给 AI 写提示词时，**直接描述最终看到的颜色**（"室内暖橙色的灯光，窗外是冷蓝色的夜色"），不要写摄影机参数。

### 色偏（绿—洋红）

- 色温是"橙—蓝"这条轴；还有一条与它垂直的"绿—洋红"轴，叫色偏（tint）。
- 荧光灯、老式路灯常带绿色，会让皮肤显得发病态；洋红偏色则会让画面显得发粉。
- 皮肤偏绿是最容易被观众察觉的颜色问题，后期优先修正。

### 混合色温

- 同一画面里有不同色温的光源，是最常用、也最好看的色彩对比：室内暖灯 + 窗外冷蓝的天光；夜景冷蓝的环境光 + 暖黄的路灯和窗户。
- 规则：**每一种颜色的光，画面里都要有对应的光源**（窗户、台灯、屏幕、篝火），观众才会信。

## 2. 光的四个维度

### 方向

| 方向 | 效果 | 常见用途 |
|---|---|---|
| 顺光（正面光） | 平、没有立体感 | 广告、证件照式的干净画面；也最容易显得假 |
| 侧光（约 90°） | 半边亮半边暗，立体、有戏剧性 | 内心冲突、严肃 |
| 侧前光（约 45°） | 立体又不过分，最常用的人像主光 | 大多数对话镜头 |
| 侧逆光 / 轮廓光 | 头发和肩膀有一圈亮边，人和背景分开 | 几乎所有好看的人像都有 |
| 逆光 | 剪影或亮边，神秘、浪漫 | 日落、出场、离别 |
| 顶光 | 眼窝发黑，压抑 | 审讯、正午烈日 |
| 底光 | 诡异 | 恐怖、讲鬼故事 |

最简单的一招：**把顺光改成侧前光，再加一点轮廓光**，脸马上就立体了。

### 软硬

- **硬光**：光源小或远（正午太阳、裸灯泡、聚光灯），影子边缘锐利，反差大，显得紧张、强烈、真实。
- **软光**：光源大或经过扩散（阴天、透过纱帘的窗光、柔光箱），影子边缘柔和，显得温柔、干净、显皮肤好。

### 强弱与光比

- **光比** = 亮面和暗面的亮度比。约 2:1 时画面平、明亮（高调）；约 4:1 时有明显的立体和戏剧感；8:1 以上时暗部几乎全黑（低调、黑色电影）。
- **高调**：整体明亮、阴影少，轻松、开放、喜剧、日系清新。
- **低调**：大面积暗部、只有局部亮，神秘、悬疑、夜戏、情绪重。

### 颜色

就是第 1 节的色温和色偏，加上彩色光（霓虹、屏幕、火光）。

### 常见布光

- **三点布光**：主光（侧前 45°）+ 辅光（另一侧，弱，填阴影）+ 轮廓光（后方）。稳妥，适合角色定妆和设定图。
- **人像光型**（按主光位置从正到侧排列）：蝴蝶光（鼻子下方有小蝴蝶形阴影，显得美）→ 环形光 → 伦勃朗光（暗面脸颊上有一个三角形亮区，经典、有质感）→ 分割光（正好半边脸亮，强烈的冲突感）。
- **动机光**：每一束光都要有画面里说得通的来源。夜里屋内的光来自台灯，脸上的蓝光来自手机屏幕。
- **实用光源**：画面里看得见的灯、蜡烛、屏幕。它们既是光源，也是构图元素；夜戏一定要安排几个。

## 3. 时间与天气

| 时间 / 天气 | 光的特征 | 写法要点 |
|---|---|---|
| 清晨 | 低角度、偏冷到偏暖，常有薄雾 | 低角度光、薄雾、长影子 |
| 黄金时刻 | 低角度暖金色、柔和、长影子 | 逆光或侧逆光拍人最好看 |
| 正午 | 顶光、硬光、影子短、反差大 | 适合烈日、压抑；不适合拍好看的人像 |
| 阴天 | 软光、低反差、偏冷 | 安静、写实、忧郁 |
| 蓝调时刻 | 天空深蓝，路灯和窗户刚亮，冷暖对比强 | 非常适合都市和情绪戏 |
| 夜晚 | 冷蓝的环境光（月光是约定俗成的冷蓝） + 暖色的实用光源 | 暗部要保留层次，不能一片死黑 |
| 室内白天 | 窗户是主光，一侧亮一侧暗 | 写明窗户在画面哪一侧 |
| 雨、雾 | 低反差，空气里有散射，地面有倒影 | 逆光下雨丝和雾气最明显 |

## 4. 色调与影调

**色调**说的是画面由哪些颜色组成；**影调**说的是明暗分布：反差多大、暗部多黑、亮部多亮。

### 配色关系

| 关系 | 说明 | 效果 |
|---|---|---|
| 互补色 | 色环上相对的两色，如橙与青（肤色与阴影） | 对比强、醒目，最常见的电影配色 |
| 类似色 | 色环上相邻的几色，如黄—橙—红 | 和谐、统一、平静 |
| 分裂互补 | 一个主色 + 它互补色两侧的颜色 | 有对比又不那么冲 |
| 单色 | 同一色相，只变明度和饱和度 | 强烈的情绪和风格化 |
| 强调色 | 整体低饱和，只有一种颜色鲜艳 | 把视线拉到关键人物或物件上 |

### 饱和度

- 高饱和：活泼、甜、动画、广告。
- 低饱和 / 去饱和：写实、冷峻、怀旧、战争、回忆。
- 局部饱和：只保留强调色。

### 影调

- **反差**：高反差显得强烈、硬朗；低反差显得柔和、梦幻、清新。
- **黑位**：暗部压到纯黑（黑位压死），显得浓郁、有力；暗部提起来变成深灰（提黑、"灰雾感"），显得像胶片、复古、柔。
- **高光**：高光柔和地过渡到白（胶片感），还是一片死白（数码感、刺眼）。

### 常见风格的配方

| 风格 | 色温 / 色调 | 影调 | 其他 |
|---|---|---|---|
| 青橙电影感 | 肤色和高光偏暖橙，阴影偏青蓝 | 中高反差 | 最通用，别过度，肤色不能发橙 |
| 暖黄怀旧 | 整体偏暖黄，饱和度略低 | 提黑、低反差 | 加颗粒 |
| 冷蓝悬疑 | 整体偏冷蓝青，低饱和 | 低调、高反差 | 只留一个暖色的实用光源 |
| 日系清新 | 略偏冷或偏青，低饱和 | 高调、低反差、略过曝 | 软光，大量留白 |
| 胶片质感 | 暗部略偏青绿，高光偏暖 | 提黑、高光柔和 | 颗粒、轻微光晕（halation） |
| 黑色电影 | 黑白，或极低饱和 | 低调、强反差、硬光 | 百叶窗影子、烟雾 |
| 赛博朋克 | 洋红和青的霓虹 | 低调、暗部深 | 湿地面的倒影、雾 |
| 莫兰迪 | 带灰的低饱和色 | 低反差 | 安静、高级、生活感 |
| 高饱和动画 | 纯色、高饱和 | 中等反差、平光 | 线条干净 |

### 肤色保护

不管调成什么风格，**肤色都要保持自然**。观众对肤色最敏感，肤色偏绿、偏紫、偏橙都会立刻出戏。调色时先看肤色，再看中性色（白墙、灰衣服）。

## 5. 色彩叙事

- **色彩剧本（color script）**：把全片每场戏的代表画面缩成小色块，按时间排成一条。一眼就能看出全片的颜色节奏：哪里冷、哪里暖、高潮在哪。阶段 2 用 `look.py swatch` 画出每场戏的色块条，排在一起给用户确认。
- **色彩弧线**：颜色随情绪变化，比如关系疏远时偏冷蓝、和解时转暖；压抑时低饱和，释放时饱和度回来。
- **人物和主题的颜色**：给主角、重要物件指定专属颜色（强调色只给它）。
- **场与场的对比**：相邻两场戏在冷暖或明暗上拉开，剪辑会更有节奏。

## 6. 镜头与光学效果

| 效果 | 写法 / 用法 | AI 生成时要注意 |
|---|---|---|
| 焦段 | 24mm 广角：空间大、近处变形；35mm：接近人眼；50mm：标准；85mm：人像，背景压缩；135mm 以上：长焦，空间压缩强 | 写焦段比写"广角""长焦"更具体 |
| 景深 / 虚化 | 浅景深：大光圈，背景虚化，主体突出；深景深：前后都清楚 | 背景虚化能掩盖 AI 背景里的瑕疵，对话镜头多用 |
| 体积光 / 丁达尔光 | 需要"逆光 + 空气里有雾或灰尘"两个条件 | 容易用过头，一场戏最多一两个镜头 |
| 镜头光晕 | 逆光对着强光源时出现 | 同上，别每个镜头都有 |
| 胶片颗粒、暗角、光晕 | 统一在后期加 | 提示词里不要写，否则每个镜头的颗粒都不一样 |
| 运动模糊 | 快速动作时自然出现 | 不要求，交给模型 |

## 7. 写进提示词

### 每个镜头写全这几样

运镜、景别、角度、主体（谁、什么神情）、运动（动多少）、**光影**（光源是什么、方向、软硬、冷暖、明暗）、焦段和景深。少写一样，模型就会自己猜。

模板：

```
（运镜），（景别），（角度），（主体：谁、什么神情），（运动：动多少）；
（光影：光源，方向，软硬，冷暖，明暗）；（焦段，景深）；（光色表里这场戏的色调那句话）
```

例子：

```
固定镜头，面部特写，平视，女孩低头看着手里的信，几乎不动，只有睫毛轻轻颤动；
画面左侧窗外的低角度暖金色夕阳侧逆光，硬光，在她左脸和头发边缘勾出亮边，右脸处在柔和的冷蓝阴影里；
85mm，浅景深，背景虚化；整体暖金与冷蓝对比，中低饱和，暗部有层次但不死黑。
```

### 写法规则

1. **写具体的光源和方向，不写形容词**。不写"电影感灯光"，写"画面右侧台灯的暖黄光，从侧前方照亮脸"。
2. **色温数字配上颜色词**。模型对"3200K"这种数字的反应不一定可靠，要写成"约 3200K 的暖橙色钨丝灯光"。第一次用时，拿同一个镜头对比一下写数字和不写数字的效果。
3. **光要和首尾帧一致**。首尾帧已经决定了光的样子，视频提示词只描述同样的光，不要另外发明。
4. **一个镜头里不换光**（AI 的弱点）。必须换光时（比如开灯），写清楚原因和时间点，并且首帧和尾帧都画出变化前后的样子。
5. **H3 用具体的英文**：官方指南明确建议，具体的视觉和声音细节比 cinematic、beautiful 这类空词有用。例如：`warm low-angle sunset light from frame left rims her hair; the right side of her face falls into soft cool-blue shadow; shallow depth of field, 85mm`。

## 8. 一场戏锁一套光色：光色表

同一场戏的所有镜头，光的方向、冷暖、时间段、色调必须完全一致。不然剪在一起，就像两部片子拼起来的。

在阶段 2 把 `palette.md` 写成光色表，每场戏一节：

```markdown
## 场 2：书院庭院（外，日）
时间 / 天气：午后，晴
主光：太阳，画面左上方的侧前光，硬光，暖（约 4500K 的暖白）
辅光 / 环境光：天空反射，偏冷，弱；光比约 4:1
实用光源：无
色调：暖金 + 青灰的互补色，中等饱和；强调色：主角的红色发带（只有它是饱和红）
影调：中高反差，暗部有层次，不压死
特殊效果：无雾；颗粒在后期统一加
色值：主 #D9A15B　辅 #6E8A8F　暗部 #2F3A3D　强调 #C2352B
中文光色句：午后左上方的暖白硬光，侧前方照亮人物，阴影偏青灰，中等饱和，暗部有层次。
英文光色句：Hard warm-white afternoon sunlight from the upper left lights the subjects from the front-side; shadows lean cool teal-grey; medium saturation with detailed shadows.
```

- 每个镜头的图片提示词和视频提示词里，**原样复制**这场戏的"中文光色句"或"英文光色句"，一个字都不改。
- 设定图统一用中性的三点布光，不带场景的光色，方便在不同场景里复用。

## 9. 检查与统一：`scripts/look.py`

```bash
python3 scripts/look.py analyze shots/s03/first.png shots/s03/takes/s03_take1.mp4
python3 scripts/look.py compare shots/s01/first.png shots/s0*/takes/*_take1.mp4
python3 scripts/look.py swatch "#D9A15B" "#6E8A8F" "#2F3A3D" "#C2352B" -o palette_scene2.png
```

- `analyze`：平均亮度、反差（2%–98% 亮度范围）、黑位和白位、平均饱和度、近中性像素的等效色温、绿—洋红色偏（Duv，偏离黑体轨迹的距离，±6‰ 以上肉眼可见）、主要颜色（色值和占比），以及一句话总结（如"低调、高反差、低饱和、偏冷"）。视频默认均匀抽 5 帧，并提示视频内部的亮度和色温漂移。
- `compare`：以第一个文件（通常是这场戏定稿的样帧或首帧）为基准，列出其他镜头在色温、亮度、饱和度、色偏上的偏差，超过阈值的标出来，并给出 ffmpeg 校正参数作为起点。
- `swatch`：把一组色值画成色块条，用于确认配色、做色彩剧本。

注意：等效色温是根据画面里接近中性的像素估算的**画面整体冷暖倾向**，不等于光源的真实色温；画面里大面积都是有色物体（比如满屏绿草）时会不准。它最适合用来**比较同一场戏的不同镜头**，不适合当作绝对数值。

### 后期调色的 ffmpeg 积木

```bash
# 冷暖：temperature 低于 6500 变暖，高于 6500 变冷；pl=1 保持亮度不变，mix 控制强度
colortemperature=temperature=5600:pl=1:mix=0.6
# 绿—洋红色偏：gg 小于 1 去绿，大于 1 去洋红
colorchannelmixer=gg=0.95
# 分区调色：暗部偏青、高光偏暖（青橙）
colorbalance=rs=-0.05:bs=0.06:rh=0.06:bh=-0.04
# 对比、亮度、饱和度、伽马
eq=contrast=1.08:brightness=0.01:saturation=0.9:gamma=1.0
# 提黑（胶片感）：把纯黑抬到约 6%
curves=master='0/0.06 0.5/0.5 1/1'
# 只提升不饱和的颜色，保护肤色
vibrance=intensity=0.15
# 套用 LUT
lut3d=file=look.cube
# 统一加颗粒和暗角（放在最后）
noise=alls=6:allf=t,vignette=PI/5
```

顺序：先校正（统一各镜头的亮度、色温、色偏）→ 再风格化（青橙、提黑、LUT）→ 最后加颗粒和暗角。全片统一用一套风格化参数，每个镜头只做校正。
