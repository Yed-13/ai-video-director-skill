# 阶段 5：白膜（greybox）运镜视频

白膜是没有材质的灰模动画：几何体搭场景、假人代表角色，只表达摄影机怎么动、人往哪走、动作在第几秒发生。作为参考视频配合首尾帧使用，能控制推镜幅度、走位方向、动作时间和先后顺序；没有人脸，也不会触发拦截。

所有镜头的白膜按分镜拼起来配上音乐，就是一版**动态分镜**：生成之前先和用户看节奏、卡点和镜头时长。

## 规格

- 画幅、分辨率和首尾帧一致；时长等于生成秒数（整数，4–15 秒）；24fps；H.264 / yuv420p，< 50MB；不要音轨。
- 场景用浅灰几何体，平光；角色用胶囊体 + 球体假人，每人一种灰度或低饱和色，头上用小锥体标出朝向；只放动作要用到的道具。
- 第 0 帧构图对上 `first.png`，最后一帧对上 `last.png`。只做走位、转身、坐下、抬手这类大动作，细节交给首尾帧和提示词。

## Codex 任务书

`codex exec --skip-git-repo-check -s workspace-write -C <项目文件夹> < 白膜任务书.txt`，路径相对项目根目录：

```
在 shots/s03/ 写一个脚本渲染白膜视频 greybox.mp4，只写代码并运行，不生成图片。
规格：1920×1080，24fps，6 秒（144 帧），H.264，yuv420p，无音轨。
构图：第 0 帧对上 first.png，最后一帧对上 last.png。
机位图：blocking/<场景>.json（米，俯视 x 右 y 下）。摄影机按镜头 s03 的 pos / aim / fov 摆，高度 <1.5 米>；人物按 characters 的位置和朝向摆。
场景：<地面、左侧柜台、背景墙……>
角色：A = 中灰假人，B = 浅灰假人，头上小锥体标朝向。
摄影机运动：<0–6 秒从 X 缓慢推近到 Y / 不动>
时间线：
  0.0–1.0 秒：全部静止
  1.0–3.5 秒：A 从画面右侧走到 62% 处停下，面朝左
  2.5 秒：B 才开始转头看 A
  5.7–6.0 秒：全部静止
工具：优先 Blender（bpy 后台模式）；没有就用 Python + numpy + Pillow 做透视投影、画平涂多边形，输出 PNG 序列后合成：
  ffmpeg -framerate 24 -i frames/%04d.png -c:v libx264 -pix_fmt yuv420p -crf 18 -an greybox.mp4
另外导出 greybox_first.png、greybox_last.png。
```

接入了 Blender MCP 时也可以自己搭。

## 对齐检查

`frames.py onion first.png greybox_first.png`，尾帧同理。假人轮廓要和角色的位置、大小基本重合，地平线和墙线对上；对不上就调白膜的摄影机，不改首尾帧。

## 提示词里的写法

白膜只提供运镜、走位和时间，画风、颜色、人物外观以首尾帧为准，**必须写明不参考它的材质**：

- 即梦：`@视频1 只作为运镜和走位参考：参考摄影机轨迹、人物移动路线和每个动作的时间；@视频1 不是要修改的素材，不参考它的灰色材质、光影和假人外形；画风、颜色、人物外观完全以 @图片1（首帧）和 @图片2（尾帧）为准。`
- H3：只能用 Ref2VA（FL2VA 不接收视频），模板见 `backends/minimax-h3.md`。

## 风险和退路

- 首尾帧 + 白膜一起用，先拿最难的一段试，可行再铺开。
- 界面不允许三者同时用时：改用首帧 + 白膜，尾帧要求写进提示词最后一段；或者只给运镜最复杂的镜头用白膜。
- 灰色渗进画面：加强"不参考材质"的写法；把白膜调亮、降低对比；还不行改成线框。
