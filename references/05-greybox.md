# 阶段 5：白膜（greybox）运镜视频

白膜视频就是一段没有材质、没有细节的灰模动画：用简单的几何体搭出场景，用假人代表角色，只表达**摄影机怎么动、人往哪走、动作在第几秒发生**。把它作为参考视频交给视频模型，再配合首尾帧，效果很好。

## 为什么要做白膜

光靠文字，下面这些问题很难控制；有了白膜，模型可以直接照着几何和时间来：

| 光靠文字时的问题 | 白膜怎么解决 |
|---|---|
| 推镜没有写的那么明显 | 摄影机轨迹精确给出 |
| 人往反方向走 | 走位路线直接看得见 |
| 动作时间和写的对不上 | 每个动作落在第几秒都是确定的 |
| 几个人同时动 | 每个假人什么时候起步，各自分开设定 |
| 运镜和走位互相冲突 | 先在白膜里排好，冲突当场就能看出来 |

另外，白膜没有人脸，不会触发写实人脸拦截。

**额外用途：动态分镜（animatic）**。把所有镜头的白膜按分镜顺序拼起来，配上音乐，就是一版动态分镜。在花钱生成之前，先和用户一起看节奏、卡点、镜头时长对不对。

## 白膜的规格

| 项 | 要求 |
|---|---|
| 画幅和分辨率 | 和首尾帧一样（比如 1280×720 或 1920×1080） |
| 时长 | 等于这个镜头的生成秒数（整数，4–15 秒） |
| 帧率 | 24fps |
| 编码 | H.264 mp4，yuv420p，单个文件 < 50MB |
| 场景 | 地面、墙、主要家具或建筑用简单几何体，浅灰色，平光或单一主光 |
| 角色 | 简单假人（胶囊体 + 头部球体），**每个角色用不同的灰度或低饱和色块**区分，头部加一个小三角形或鼻子标出朝向 |
| 道具 | 只放动作要用到的道具，用简单几何体 |
| 镜头 | 焦距和机位要让第 0 帧的构图对上 `first.png`，最后一帧对上 `last.png` |
| 动作 | 只做走位、转身、坐下、抬手这类大动作；表情和手指的细节交给首尾帧和提示词 |
| 声音 | 不要音轨（`-an`） |

## 让 Codex 做白膜

在项目根目录运行 `codex exec --skip-git-repo-check -s workspace-write -C <项目文件夹> < 白膜任务书.txt`。任务书模板（路径都相对项目根目录）：

```
在 shots/s03/ 里写一个脚本，渲染一段白膜（greybox）视频 greybox.mp4。不要生成图片，只写代码并运行。
规格：1920×1080，24fps，共 6 秒（144 帧），H.264，yuv420p，不要音轨。
参考构图：first.png 是第 0 帧应有的构图，last.png 是最后一帧应有的构图。
场景：<用简单几何体描述：地面、左侧柜台、背景墙……>
角色：A = 中灰假人（在 first.png 中的位置），B = 浅灰假人……，头部用小锥体标出朝向。
机位图：blocking/<场景>.json（单位米，俯视 x 向右、y 向下）。按里面镜头 s03 的 pos / aim / fov 摆放摄影机，人物按 characters 的位置和朝向摆放；摄影机高度 <1.5 米 / 低机位 0.5 米……>。
摄影机：<运动：0–6 秒从 X 缓慢推近到 Y，或保持不动>
时间线：
  0.0–1.0 秒：所有物体静止
  1.0–3.5 秒：A 从画面右侧走到 62% 位置停下，面朝左
  2.5 秒：B 才开始转头看 A（比 A 晚）
  5.7–6.0 秒：全部静止
渲染工具：优先用 Blender（bpy，后台模式）；没有就用 Python + numpy + Pillow 自己做透视投影，把几何体画成平涂多边形，输出 PNG 序列，再用 ffmpeg 合成：
  ffmpeg -framerate 24 -i frames/%04d.png -c:v libx264 -pix_fmt yuv420p -crf 18 -an greybox.mp4
完成后额外导出第 0 帧和最后一帧：greybox_first.png、greybox_last.png。
```

这个会话里如果接入了 Blender MCP，你也可以自己用它搭白膜，不交给 Codex。

## 对齐检查

```bash
python3 scripts/frames.py onion shots/s03/first.png shots/s03/greybox_first.png
python3 scripts/frames.py onion shots/s03/last.png  shots/s03/greybox_last.png
```

叠图里，假人的轮廓要和首尾帧里角色的位置、大小基本重合；地平线和主要墙线也要对上。对不上就调白膜的摄影机，不要改首尾帧。

## 在提示词里怎么用白膜

关键：**白膜只提供运镜、走位和时间；画风、颜色、人物外观全部以首尾帧为准**。一定要明确写出不参考它的材质，否则灰色和假人的样子可能被带进成片。

- **即梦**：`@视频1 只作为运镜和走位参考：参考它的摄影机运动轨迹、人物移动路线和每个动作发生的时间。不参考它的灰色材质、光影和假人外形。画风、颜色、人物外观完全以 @图片1（首帧）和 @图片2（尾帧）为准。`
- **H3**：必须用 Ref2VA 模式（FL2VA 不接收视频）。写法见 `backends/minimax-h3.md`。

## 风险和退路

- **还没验证过的组合要先试**：首尾帧 + 白膜一起用的效果，先拿最难的一个镜头试，确认可行再全部铺开。
- **界面不让三者同时用时**（即梦某些模式下首尾帧和参考视频互斥）：退一步用"首帧 + 白膜"，尾帧的要求改写进提示词的最后一段；或者只给运镜最复杂的镜头用白膜。
- **灰色渗进画面**：在提示词里加强"不参考材质"的说法；把白膜的灰度调亮、对比调低；还不行就把白膜改成线框风格（只画边线）。
- **模型把白膜当成要编辑的源视频**：提示词里明确写"@视频1 不是要修改的素材，只参考它的运动"。
