# 提示词成套示例

都是原创示例，用同一个小故事串起来：**老人每天给巷口的流浪猫留一碗饭。** 结构来自实际试拍（按场母版在 Seedance 2.5 上用过），具体句子没有逐条生成验证：照结构写，不照抄。其他风格的示例在 `styles/` 各文件末尾，运镜写法在 `camera-moves.md`。

## 1. 画风句（写进 brief.md，之后原样复制）

```
写实：真实电视剧画面，像用 35mm 电影胶片拍的市井生活剧：皮肤有毛孔和细纹，旧衣服有洗过的褶皱，
墙皮斑驳，物体有重量和接触阴影；可见的胶片颗粒；色调温暖、饱和度略低，暗部保留细节。
```

## 2. 设定图提示词（角色定妆）

```
<画风句>
一张角色定妆图，白底，全身，正面站立，双手自然下垂，不拿东西，表情平静。
老人：约 72 岁中国男性，身高约 168 厘米，偏瘦，背略驼；花白短发，额头和眼角皱纹深，
左眉上方一颗痣；深蓝色旧棉布外套，扣子扣到最上面一颗，灰色长裤，黑色布鞋。
中性的三点布光，没有环境，没有文字和水印。画幅 16:9，人物在画面中间。
```

## 3. 首帧提示词

```
<画风句>
画幅 16:9。清晨的老巷口，固定机位的全景，机位在巷子里朝巷口看，约胸口高度，35mm。
VIEW：画面左侧是一面斑驳的红砖墙，墙根放着一只白色搪瓷碗（空的）；画面中间偏右是老人，
背对镜头蹲着，只看到背影和右侧脸颊的轮廓；画面右侧是一扇关着的绿色木门；巷口在画面深处，亮。
老人外观以参考图为准，右手拿着一只铝饭盒，盒盖开着，手在碗的上方、还没碰到碗。
光：清晨六点的冷白天光从巷口（画面深处）照进来，逆光，老人的肩和发边有一圈亮边，
巷子里是柔和的冷灰阴影；不开灯。
画面里没有猫。墙上和门上的字都在景深外，只是模糊的笔画影子。
```

要点：手已经在碗的上方（难的接触动作交给首帧）；画外的东西不写；"没有猫"是首帧提示词里可以写的，视频提示词里不写。

## 4. 视频提示词：最短有效版（单镜，图生视频）

```
@图片1 作为首帧。老人把饭盒里的饭拨进搪瓷碗，拨三下，停住，把饭盒盖上。
固定机位，日常速度。碗始终在墙根原位。
```

出来缺什么补什么。比如饭盒变形了，只加一句：`饭盒是硬的铝制方盒，形状不变。`

## 5. 视频提示词：带节奏版（单镜，一句台词）

```
@图片1 作为首帧，@图片2 是老人的外观（只参考人物）。
整段 8 秒，一个连续镜头，固定机位的全景，不推不拉不摇。
开头和首帧一样。老人用筷子把饭盒里的饭拨进碗里，拨三下，动作慢，第三下之后筷子在碗沿上轻轻磕一下。
他把饭盒盖上，手撑着膝盖，停了一下，朝巷口的方向偏一点头。
老人说（声音不大，像自言自语，尾音往下落）：「吃饭了。」
说完他不动，还蹲着，只有呼吸。
声音：筷子碰搪瓷碗的轻响，饭盒盖扣上的一声；清晨的巷子，远处有自行车铃。没有背景音乐，不加字幕。
<光色句> <画风句>
```

## 6. 视频提示词：按场母版（两个镜头，15 秒）

```
【参考】@图片1 是首帧，也是镜头一的机位和构图；@图片2 是老人的长相和衣服（只参考人物，不参考背景）；
@图片3 是镜头二的机位和构图（只参考机位、构图和巷子，人物动作以文字为准）；@图片4 是那只橘猫的外观。
【前情】老人独居，老伴去年走了。这只橘猫以前是老伴喂的，他一直嫌它脏。老伴走后，他每天清晨照着老伴的
样子留一碗饭，猫从来不在他面前吃。以上发生在这场之前，只作为背景，不在画面和声音里出现。
【这场戏】又一个清晨，他照常来留饭。
【他此刻】他不承认自己在等这只猫。放下饭就该走，但今天他想多待一会儿，又怕把猫吓跑，所以装作在系鞋带。

【镜头总览】整场 15 秒，两个镜头：镜头一约 0–7 秒，镜头二约 7–15 秒，硬切。
【开场】画面一开始就是 @图片1：他已经蹲在墙根，饭盒开着。环境声一开始就在，不从静音开始。

【镜头一｜约 0–7 秒】
机位：@图片1 的机位。三脚架在巷子里、胸口高度，35mm，全景，全程不动。焦点在老人身上。
画面：画面左侧是红砖墙和墙根的搪瓷碗；中间偏右是背对镜头蹲着的老人；右侧是绿色木门；巷口在深处，亮。
表演：他用筷子把饭拨进碗里，拨三下，一下比一下慢。拨完没有马上盖饭盒，筷子停在半空，
头朝巷口偏了一点，像在听。然后才把饭盒盖上。
声音：筷子碰搪瓷的轻响；饭盒盖扣上。
怎么切出：在他一只手撑着膝盖、身体刚开始往上起的半途，切到镜头二。

【镜头二｜约 7–15 秒】
机位：@图片3 的机位。摄影机贴近地面，在碗的后方朝巷口看，50mm，固定。焦点在碗上。
画面：前景是墙根的搪瓷碗，清楚；画面右侧是老人的小腿和布鞋，虚焦；巷口在画面深处。
表演：镜头二开始时他正好站直。他没有走，一只脚往后撤了半步，蹲下去解开鞋带又系上，动作很慢。
系到一半，@图片4 的橘猫从画面左侧的墙根探出头，停住，看着他的方向。他的手停了。
猫贴着墙走到碗边，低头闻了闻，开始吃。他的手这才接着把鞋带系完，没有抬头。
声音：鞋带摩擦的细响；猫吃东西的轻响；他鼻子里很轻的一次出气。

【结尾交接】猫在吃，他蹲着不动，保持约 2 秒。不淡出，不加转场。
【台词与声音】这一场没有台词，他全程闭着嘴，只有呼吸。环境声全程连续，切镜时不断：
清晨的巷子，远处的自行车铃和一两声鸟叫。没有背景音乐，没有旁白，不加字幕。
【光】<光色句>，整场光线不变。
【画风】<画风句>
【人物】老人：外观以 @图片2 为准。<人物卡>　橘猫：外观以 @图片4 为准，成年，偏瘦，左耳有一个小缺口。
【动作幅度】像纪录片里偷拍到的普通人：每个镜头只有一个主要动作，其余时间只有呼吸、眨眼和很小的视线变化；
人和猫都不看镜头。切镜前后，姿势、位置、手里的东西和光完全接得上。
【文字】墙上和门上的字都在景深外，只是模糊的笔画影子。
【约束】只有一个老人、一只猫、一只碗；饭盒和碗的形状不变，碗不移动；不加任何转场特效。
```

## 7. 接续上一场的开头写法

```
【参考】@视频1 是上一场的结尾。本场从 @视频1 的最后一帧接着拍，@视频1 只用来接续，不是要修改的素材；
@图片1 是镜头二的机位和构图……
【开场】接着 @视频1 的最后一刻：猫还在吃，他还蹲着，光和环境声不变。
【镜头一｜约 0–3 秒】机位：沿用 @视频1 最后的机位，不动。……约 2 秒后再切。
```

## 8. 漫剧（竖屏，一段三个镜头，带时间）

```
【参考】@图片1 是首帧；@图片2 是林晚的角色设定；@图片3 是陈默的角色设定；@图片4 是楼道场景（只参考场景）。
林晚是 @图片2 里的短发女孩，陈默是 @图片3 里穿灰色卫衣的男生。
【这场戏】深夜的旧楼道。林晚以为陈默三年前就离开了这座城市。
整段 10 秒，9:16，三个镜头，硬切。
0-3 秒，镜头一：中景，固定机位。林晚推开楼道的门，手还搭在门把上，愣在门口。
3-6 秒，镜头二：切到陈默的近景，他背对镜头站在窗边，先停一拍，慢慢转过身，只转到侧脸。
6-10 秒，镜头三：切回林晚的大特写，她后退半步，眼睛睁大，定住。
林晚说（很轻，尾音发抖）：「……怎么是你？」
说完她闭上嘴，画面停 1 秒。
声音：楼道里声控灯的电流声，远处一声关门。没有背景音乐，不加字幕。
<画风句：2D 手绘动画……不是 3D 渲染>
人物外观、发型、服装与角色设定一致，三个镜头里完全一样。
```
