# 阶段 1：故事

不画任何图。

## 流程

1. 用户说想法或初步剧情。追问片长、配歌（歌名、时长、BPM）、参考片。
2. 来回讨论补全故事；不清楚就问，不要脑补。
3. 用户确认梗概后，展开成逐镜头故事写进 `story.md`。有台词就按下面的剧本格式写。
4. 另开子 agent，只给 `story.md`，用 `review-briefs.md` 第 1 份审。改完交用户定稿。

## 要求

- 开头写一句话主题；写不出来，说明故事还没想清楚。
- 首选**片段式**（镜头之间不用接戏）；连贯式最容易穿帮，用户要求才用。
- 每个转折按现实追问：为什么、东西从哪来、够得着吗、真会这样吗（用户要超现实除外）。
- 最抓眼球的画面放在开头，写明第几秒出现。
- 包袱和转折按"问题 → 主角怎么解决 → 旁人什么反应"写；反应要有先后，身体细节要对（吃惊往后缩）。
- 绕开 AI 难拍的：人物交叉、手拿小东西、文字、镜子和倒影、左右不对称特征（非用不可时设定图里写死哪侧）、一镜内换光、一人连做三个动作、俯拍看不到脸、配角太多。
- 配歌时，转折对副歌，关键动作对重拍。
- 短剧：一集一个主冲突，开头 3 秒出冲突，结尾停在悬念，不提前和解；5 分钟约 750–1000 字台词。

## 剧本格式（有台词时）

只写拍得到的东西：不写"他心里很难过"，写"他低下头，手指攥紧衣角"，或写成内心独白。三种声音分开标，后面的提示词写法不同。

```
本场出场人物：羊羊、评判老师、李秀才

1-1 古镇书院庭院 [外] [日]
△ 羊羊一身朴素布衣，站在院子中央，神情平静。
【音效】人群窃窃私语、低笑。
羊羊：（平淡）其实，我是诗仙。
△ 众人一愣，随即哄笑。
评判老师（内心独白）：无论他吟什么诗，只要老夫在场，他绝不可能赢。
羊羊（画外音）：……
```
