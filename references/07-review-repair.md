# 阶段 7：收片、检查、修复

```bash
python3 scripts/clip.py inspect shots/s03/takes/s03_take1.mp4 --first shots/s03/first.png --last shots/s03/last.png
python3 scripts/look.py compare <这场戏的基准帧> shots/s03/takes/s03_take1.mp4
```

`clip.py` 输出到 `shots/s03/review/s03_take1/`：先看 `contact.jpg`；再看 `info.txt`（基本信息、首尾帧 SSIM、漂移、结尾跳变和首帧过锐的提示），可疑处放大看 `frames/`。

逐项查：动作和先后顺序、方向；人数、道具数量、凭空出现的东西；脸、手、身形变形；同一个人出现两次；场景矛盾（夜景窗外是白天）；开头结尾突变；颜色漂移和与同场其他镜头不一致；嘴自己动；台词有没有念错（语音识别核对）；声音是否像同一个人。

写进 `review/s03_take1/report.md`：时间、帧号、问题、处理建议，最后写明你没法确认的（动作流畅感、节奏、声音听感）。

## 处理顺序：剪 → 修 → 补 → 重拍

1. **剪**：问题只在头尾几帧，剪掉。
2. **修**：结尾跳变就停在最后一张好帧；第一帧过锐就删掉；漂移或颜色不一致按 `look.py` 的参数校正；推镜不够在后期缩放；节奏不对就变速或抽帧。
3. **补**：问题在中间一小段时，`clip.py stills --at <秒>` 截出出问题前的最后一张好帧，让 Codex 修好作为新首帧（需要时再画尾帧），只重新生成这一小段，剪回原位。
4. **重拍**：先改提示词、首尾帧或白膜，找到原因再拍；只想换一种结果就换 seed。只重拍这一段。

旧 take 一律保留，最后一起挑。

## 已知的模型习惯（每做完一支片子补充）

- Seedance 较新版本：写了"没有音乐"有时仍混入音乐；结尾可能突然跳到尾帧；第一帧可能过锐。
- Seedance 2.0 mini：越往后越暗、越冷；自带音效常能直接用。
- MiniMax H3 本地 768p：质量很依赖提示词是否接近官方格式；小字和细节容易糊；自带声轨常有乱语和它自己生成的背景音乐。
