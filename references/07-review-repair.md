# 阶段 7：收片、检查、修复

```bash
python3 scripts/clip.py inspect shots/s03/takes/s03_take1.mp4 --first shots/s03/first.png --last shots/s03/last.png
python3 scripts/look.py compare <这场戏的基准帧> shots/s03/takes/s03_take1.mp4
```

`clip.py` 输出到 `shots/s03/review/s03_take1/`：先看 `contact.jpg`；再看 `info.txt`（基本信息、首尾帧 SSIM、漂移、结尾跳变和首帧过锐的提示），可疑处放大看 `frames/`。

逐项查：动作和先后顺序、方向；人数、道具数量、凭空出现的东西；脸、手、身形变形；同一个人出现两次；场景矛盾（夜景窗外是白天）；开头结尾突变；颜色漂移和与同场其他镜头不一致；嘴自己动；台词有没有念错（语音识别核对）；声音是否像同一个人。

按场生成和有声音的段落另外查：

```bash
python3 scripts/scene.py cuts <视频> --plan 5,10        # 实际切点和计划对比（模型常早切 0.5–2 秒）
python3 scripts/scene.py voice <视频>                   # 什么时候有人声
python3 scripts/scene.py spectro <视频>                 # 频谱图：谐波条纹是正常发声，只有噪声带是耳语或气声
python3 scripts/scene.py strip <视频> --crop 200:120:860:520 --every 0.25   # 嘴部裁切排一行，看不说话的人嘴动没动
```

- **把实际画面的左右、视线、道具位置记下来**，下一段按实拍写，不按原计划写：模型不一定照参考图，新一版的左右可能和上一版相反。
- 背影画面里，画面左侧就是人物的左手。拿不准就放大核对。
- 这些声音检查判断不了字对不对；字要靠语音识别或用户听。
- 抽样片时，同一轮的几条一起看，先分清是随机问题还是结构问题（`gacha.md`）。

写进 `review/s03_take1/report.md`：时间、帧号、问题、处理建议，最后写明你没法确认的（动作流畅感、节奏、声音听感）。

## 处理顺序：剪 → 修 → 补 → 重拍

1. **剪**：问题只在头尾几帧，剪掉。多出来的物体在画面边缘时先试裁切（放大 1.18 倍以内可接受）；越轴的无字侧脸镜头可以水平翻转。
2. **修**：结尾跳变就停在最后一张好帧；第一帧过锐就删掉；漂移或颜色不一致按 `look.py` 的参数校正；推镜不够在后期缩放；节奏不对就变速或抽帧。
3. **补**：问题在中间一小段时，`clip.py stills --at <秒>` 截出出问题前的最后一张好帧，让 Codex 修好作为新首帧（需要时再画尾帧），只重新生成这一小段，剪回原位。
4. **重拍**：先改提示词、首尾帧或白膜，找到原因再拍；只想换一种结果就再抽几条样片。只重拍这一段。

**停止条件**：同一类结构问题连续两轮没解决，就换拍法（换机位、拆镜头、改首帧让动作已完成一半、把复杂握取换成已握住、把全身行走换成上半身、把大环绕换成两个固定机位），不再加字，也不急着换模型。核心卖点本身就是模型做不到的精确动作时，告诉用户改实拍或可控的 3D 动画。

## 问题 → 先判断 → 优先尝试

| 问题 | 先判断 | 优先尝试 |
|---|---|---|
| 皮肤像塑料 | 首帧就假，还是动起来才假 | 先改首帧的光和皮肤；删磨皮式的风格词 |
| 主体外形漂移 | 大运镜是不是露出了没给过的角度 | 缩小运动范围，补对应角度的参考 |
| 物体浮起来 | 首帧里接触清不清楚 | 强化底座接触和阴影，减少主体移动 |
| 手穿过物体 | 接触动作是不是太复杂 | 首帧改成已经握住，或拆成前后两镜 |
| 全程像慢动作 | 有没有 slow、dreamy、dramatic 一类词 | 写明正常速度，删冲突词 |
| 摄影机乱晃 | 文字和预设是不是矛盾 | 只留一种运镜，必要时固定机位 |
| 背景融化 | 主体动作和运镜是不是同时太大 | 简化背景，减少遮挡变化 |
| 明暗闪动 | 是不是要求了多种效果同时变 | 固定光源，不同时改时间和天气 |
| 文字变形 | 是不是把精确文字交给了生成 | 后期叠加或屏幕合成 |
| 写实片看起来像动画 | 是首帧材质、动作还是构图造成的 | 分别定位，不反复加"写实" |
| 脸越动越变 | 转头幅度、遮挡后重新出现 | 减小转头，换角度合适的参考，拆镜头 |
| 同一人声音忽大忽小 | 提示词里有没有发声方式的词 | 整场一段发声描述（`acting-voice.md`） |
| 画风跑偏（2D 变 3D 等） | 首帧画风对不对 | 见 `styles/` 对应文件 |

旧 take 一律保留，最后一起挑。

## 已知的模型习惯（每做完一支片子补充）

- Seedance 较新版本：写了"没有音乐"有时仍混入音乐；结尾可能突然跳到尾帧；第一帧可能过锐。
- Seedance 2.5（样片模式实测）：按场多镜生成时人物、服装、房间保持得住；会自己调切点；音频参考只取音色，不照搬时间；签名和手写字会变成清晰的假英文；提到的东西即使写的是"看不到"也会画出来。
- Seedance 2.0 mini：越往后越暗、越冷；自带音效常能直接用。
- MiniMax H3 本地 768p：质量很依赖提示词是否接近官方格式；小字和细节容易糊；自带声轨常有乱语和它自己生成的背景音乐。
