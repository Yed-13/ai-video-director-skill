# 可选：四线程协作

用户希望你尽量自主推进、少打扰时使用。你当"主做"，再开三个长期存在的子 agent。

| 角色 | 负责 |
|---|---|
| 主做（你） | 所有制作 |
| 审核 | 每一步都检查，只挑错不改文件；提交生成之前必须明确写"通过" |
| 监督 | 读完用户说过的所有话，整理成要求清单；每一步检查有没有人（包括你）忘了某条要求 |
| 代理 | 读完用户说过的所有话，整理成用户的偏好；你和审核拿不准时，或者要提交生成时，由它按用户的偏好做决定，写明依据和把握程度 |

用户说过的话：Claude Code 的会话记录在 `~/.claude/projects/` 下面；或者让用户给一份要求文件。

## 配合顺序

1. 你每做完一步，先交给审核，再交给监督。
2. 有分歧时交给代理决定。
3. 所有决定和花费都记进 `log.md`。用户回来后可以推翻任何决定。

## 边界

- 代理只能在用户事先给定的预算或积分上限内批准提交，超出就停下来等用户。
- 因为视频由用户手动生成，代理"批准提交"的意思是：把提交包标记为"可以生成"，并在 `log.md` 里写一行，等用户来点生成。
- 不充值、不买额度。额度用完就停，先把已有片段粗剪出来。
