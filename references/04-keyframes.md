# 阶段 4：首尾帧

只靠文字生成视频容易出逻辑错误，小物件（雨、帽子、纹身）也会中途消失；首尾帧都画上才稳。多镜对话段可以不画首尾帧，改喂身份板、场景图和站位大全景（`02-shotlist.md`）。

## 先写后画

每个镜头先写文字，全部写完交给审核 agent（`review-briefs.md` 第 2 份），通过再让 Codex 画：

```
s03
首帧：谁在哪、什么姿势和表情、画面里有哪些东西（照机位图的画面左右表）
中间：发生了什么
尾帧：……
```

## 画的顺序

1. 先画内容最多的那张（通常是尾帧），再以它为 `-i` 输入改出首帧，保证机位和构图一致。
2. 同一地点、同一机位的镜头，在前一张图上改，不重画。
3. 推镜头：尾帧直接从首帧裁一块放大（`frames.py crop --zoom`）。首尾帧构图完全一样时，模型会当成摄影机不动。
4. 统一裁成目标画幅，首尾帧像素尺寸一致（`pack.py` 会检查）。
5. 光的方向和冷暖照光色表画。

画完后按 `review-briefs.md` 第 2 份的检查项自己过一遍，再交给审核 agent。最常漏的几项：动作要用到的东西首帧里必须有；做反应的人要提前摆在后面、脸朝镜头（一段视频没法中途切过去拍他）；多人别摆同一姿势；首尾帧叠图看，不该变的地方一点都不能变（墙色差一点，视频里墙会慢慢变色）。

## 改图

Codex 只改一小块也会重绘整张图，别处可能悄悄变了。只改局部时，用 Python / Pillow 把改好的那块贴回原图。新版本存 `first_v2.png`，旧的不删。
