# 阶段 4：首尾帧

首尾帧就是每个镜头的第一张画面和最后一张画面。这是降低抽卡率最关键的一步：只靠文字生成视频，模型很容易出逻辑错误；而雨、帽子、纹身这类小东西只写在文字里，拍着拍着就会消失。只有首帧和尾帧里都画上，才稳。

## 先写后画

每个镜头先写一段文字说明，再开始画：

```
s03
首帧：……（谁在哪、什么姿势、什么表情、画面里有哪些东西）
中间：……（发生了什么）
尾帧：……
```

全部镜头写完后，交给审核 agent 看一遍（这一步只看文字，很便宜）。通过了再让 Codex 画。

## 画的顺序

1. **先画内容最多的那一张**，通常是尾帧。
2. **在尾帧上改出首帧**（把尾帧作为 `-i` 输入，只改要变的部分）。这样两张图的机位和构图是一致的。
3. **同一地点、同一机位的镜头，直接在前一张图上改**，不重新画。
4. **推镜头**：尾帧可以直接从首帧裁一块放大（`scripts/frames.py crop`）。如果首尾帧构图完全一样，模型会认为摄影机不动，推镜效果就出不来。
5. **画幅**：Codex 出的图不一定正好是 16:9。交付前统一裁成目标比例，并且首帧和尾帧的像素尺寸必须完全一样（`scripts/pack.py build` 会检查）。

## 画完的检查项

每张图都要放大看。材料：首帧、尾帧、设定图、这个镜头的分镜。

1. **动作要用到的东西，首帧里必须有**。后面要拿杯子，首帧里就要看得到杯子，否则杯子会凭空出现。
2. **别人的反应要提前摆好**。一段视频就是一个镜头，没法中途切过去拍别人。所以首帧里就要安排好：一个人在前面做事，另一个人在后面、脸朝镜头，方便做反应。
3. **多人不能摆同一个姿势**，否则模型会让所有人同时动。
4. **给动作留空间**：东西要落到、飘到的地方要提前空出来；人的头顶要留点空。
5. **风向统一**：围巾往左飘，床单就不能往右飘。
6. **缩到手机大小看一遍**：`scripts/frames.py phone`。远处的人太小、看不清，就要改。
7. **放大找多余的东西**：多出来的水壶、奇怪的细线、多一根手指。
8. **首尾帧叠在一起看**：`scripts/frames.py onion first.png last.png`。不该变的地方两张图必须一样。墙的颜色差一点，视频里墙就会慢慢变色；杯子大一点，视频里杯子就会慢慢变大。

## 改图

- Codex 就算只改一小块，也会把整张图重新生成一遍，其他地方可能悄悄变了。所以只改一小块时，**把改好的那一块贴回原图**（用 Python/Pillow 按区域合成），而不是直接用 Codex 返回的整张图。
- 新版本存为 `first_v2.png`，旧的不删。
