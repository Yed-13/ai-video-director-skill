# 阶段 4：首尾帧

只靠文字生成视频容易出逻辑错误，小物件（雨、帽子、纹身）也会中途消失；首尾帧都画上才稳。按场生成的段落画首帧和每个镜头的构图参考，不画尾帧（`02-shotlist.md`）。

首帧提示词写外观、环境、光、构图和这个机位的视野，不写动作过程（示例见 `prompt-examples.md` 第 3 条）。画风跟着 `styles/` 里对应的文件。

## 先写后画

每个镜头先写文字，全部写完交给审核 agent（`review-briefs.md` 第 2 份），通过再让 Codex 画：

```
s03
首帧：谁在哪、什么姿势和表情、画面里有哪些东西（照机位图的画面左右表）
中间：发生了什么
尾帧：……
```

## 画的顺序

1. 先画内容最多的那张（通常是尾帧），再以它为 `-i` 输入改出首帧，保证机位和构图一致。
2. 同一地点、同一机位的镜头，在前一张图上改，不重画。
3. 推镜头：尾帧直接从首帧裁一块放大（`frames.py crop --zoom`）。首尾帧构图完全一样时，模型会当成摄影机不动。
4. 统一裁成目标画幅，首尾帧像素尺寸一致（`pack.py` 会检查）。
5. 光的方向和冷暖照光色表画。
6. 难的接触动作交给首帧：手已经在物体旁边或已经握住，视频里只做剩下的一半。
7. 每张出 2–4 个候选挑一张（`gacha.md` 第 2 层）；成片里已经对的画面可以直接截下来当后续镜头的首帧或样板。

画完后按 `review-briefs.md` 第 2 份的检查项自己过一遍，再交给审核 agent。先看这张图**暂停着是不是就成立**（写实片：像不像照片）：主体有没有被裁、接触处有没有阴影、有没有被镜像、材质是不是全像塑料。最常漏的几项：动作要用到的东西首帧里必须有；做反应的人要提前摆在后面、脸朝镜头（一段视频没法中途切过去拍他）；多人别摆同一姿势；首尾帧叠图看，不该变的地方一点都不能变（墙色差一点，视频里墙会慢慢变色）。

## 首帧样片（生成视频之前必做）

首帧出齐后，按顺序拼成一条静帧样片，每张停它在片里的秒数，有台词就配上台词时长或临时配音：

```bash
python3 scripts/scene.py animatic post/animatic_v1.mp4 shots/s01/first.png:4 shots/s02/first.png:5 shots/s03/first.png:6
```

你先抽帧自查，再交给用户看：故事讲清了吗、镜头有没有重复、节奏拖不拖、相邻两镜接不接得上（卷子怎么从空白变成签好名的、人怎么从站着变成坐着）、道具位置前后一致吗。静帧样片都不成立，生成出来也不会成立。用户确认后才进入视频。

## 改图

Codex 只改一小块也会重绘整张图，别处可能悄悄变了。只改局部时，用 Python / Pillow 把改好的那块贴回原图。新版本存 `first_v2.png`，旧的不删。
