# 阶段 3：画风与设定图

## 定画风

1. 问用户有没有参考图。有就最好，作为 `-i` 传给 Codex。
2. 你写提示词，Codex 画 2–3 张**样帧**（选分镜里最有代表性的一两个镜头）。不同方案放进 `style/`。
3. 用户挑一张，或者说出要怎么改。改到用户满意为止。
4. 把定下来的画风写成**一句固定描述**，记进 `brief.md`。后面所有图片提示词和视频提示词都原样使用这句话，比如：
   - 干净的现代 2D 手绘动画，平涂色块，线条利落，没有颗粒和纹理
   - 柔和的水彩质感，暖色调，纸张纹理轻微可见

用户确认画风之前，不画任何正式镜头。

## 设定图（相当于"选角"）

画风定好以后，给每个主要角色、每个场景和反复出现的道具出图，放进 `sheets/`。这些图在视频阶段作为参考图喂给模型，图越干净，各段里的人就越像同一个人。

### 角色：先出定妆图，再出身份板

**定妆图**（一张）：
- 全身、正面、白底，双手自然垂下，手里不拿东西，表情平静；
- **一定要写鞋子**，不写的话模型很容易只出半身；
- 写清身高、体型、年龄、脸型、眼睛、发型发色、服装，和故事的年代对得上；
- 成年角色大约 8 头身；反派也别丑得太极端；
- 群众演员不单独设计；
- 用中性的三点布光，不带场景的光色。

**身份板**（定妆图确定后，以它为参考再出一张 16:9 的图）：
- 中间偏左放一张大的正面全身像；周围放背面、侧面全身，坐姿、蹲姿各一张，再放 3 个表情特写；
- 所有图互不重叠，脸、手、脚都不能被裁掉；所有角度保持同一张脸、同一个发型、同一套衣服、同样的身材比例；
- 白色或米白色背景，没有环境、道具、水印；角落放一张简洁的角色卡（名字、身份、性格关键词）；
- 看起来像动画工作室的角色设定页，不是海报。

**不要拿真人照片（尤其是明星）当参考**：平台会拦截，也有肖像权风险。

### 场景图

- **画面里不能有人**，和人物用同一种画风，并且按光色表里这场戏的光色来画。
- **对话戏出三张**，和机位图对应（见 `camera-blocking.md`）：
  - 正打：从 A 这边看过去（B 身后的背景）；
  - 反打：从 B 这边看过去（A 身后的背景）。在正打图上改：左右内容互换、前后内容互换，原来远处的门和背景换成符合这栋建筑风格的墙；
  - 站位大全景：从 1 号总角度看，能看清所有人站在哪（可以先画空场景，再画一版带人物站位的）。
- 视频阶段每段只喂**一张**场景图。

### 道具图

- 纯白底，没有背景和人；
- **写实际尺寸**，比如"茶杯直径约 8 厘米，一只手能握住"，并且在视频提示词里也写一遍同样的尺寸。不写的话，视频里道具会忽大忽小。

在设定图的提示词里把固定特征写死：

- 不对称的特征写清楚在哪一侧（"纹身在**左**前臂外侧"）。
- 服装的颜色和层次（"深蓝外套，里面白 T 恤，外套拉链永远拉开"）。
- 发型和配饰。

把这些固定特征再抄一份到 `brief.md` 的"人物卡"里，后面写视频提示词时直接复制，一个字都不改。

## 写给 Codex 的图片提示词要点

- 第一行固定写 `Use your image generation tool to create exactly ONE image. Do not run shell commands.`
- 写清楚：画风那句话、画幅比例（16:9）、构图（人物在横向 38% 或 62% 处）、配色（引用 `palette.md` 里的色值）、角色（引用人物卡）。
- 一次只画一张。Codex 额度有限，用完就等它恢复，不要一次排很多张。
