# 后端：即梦 Seedance 2.x（网页端，用户手动生成）

## 输入限制

| 类型 | 上限 | 格式 | 大小 |
|---|---|---|---|
| 图片 | ≤ 9 张 | jpeg / png / webp / bmp / tiff / gif | 每张 < 30MB |
| 视频 | ≤ 3 段 | mp4 / mov | 每段 < 50MB，总时长 2–15 秒 |
| 音频 | ≤ 3 段 | mp3 / wav | 每段 < 15MB，总时长 ≤ 15 秒 |
| 总数 | ≤ 12 个文件 | | |

输出 4–15 秒，自带音效 / 配乐，最高约 720p。**上传写实人脸会被拦截**（白膜和 2D / 卡通画风不受影响）。

## 模式选择

- **首尾帧模式**：只能传首帧和尾帧两张图，不能加参考视频。
- **全能参考（多模态参考）模式**：图片、视频、音频都能传，在提示词里用 `@图片1 作为首帧`、`@图片2 作为尾帧` 指定首尾帧，再用 `@视频1` 指定白膜。**首尾帧 + 白膜要用这个模式。**

即梦的界面会更新。如果当前界面的行为和上面不一样，以界面为准，并把发现写进 `lessons.md`。

## 引用规则

- 引用写法：`@图片1`、`@视频1`、`@音频1`。编号按**同类素材的上传顺序**分别计数。
- 每个引用都必须写明用途，不能只写"参考 @视频1"：

| 用途 | 写法 |
|---|---|
| 首帧 / 尾帧 | `@图片1 作为首帧`、`@图片2 作为尾帧` |
| 角色外观 | `人物外观参考 @图片3` |
| 场景 | `场景参考 @图片4` |
| 运镜 / 走位（白膜） | 见下文 |
| 动作 | `参考 @视频2 的动作编排` |
| 节奏 | `视频节奏参考 @视频2` |
| 配乐 | `背景音乐参考 @音频1` |

## 从母版翻译成即梦提示词

把七段式母版去掉标签，按顺序连成一段中文（或保留【】标签，两种写法都可以），开头先交代素材用途：

```
@图片1 作为首帧，@图片2 作为尾帧。@视频1 只作为运镜和走位参考：参考它的摄影机运动轨迹、人物移动路线和每个动作发生的时间，@视频1 不是要修改的素材，不参考它的灰色材质、光影和假人外形；画风、颜色、人物外观完全以 @图片1 和 @图片2 为准。
【画风】……
【镜头】……
【构图与配色】……
【人物】……
【逐秒】……
【声音】……
【约束】……
```

没有白膜时，删掉 `@视频1` 那一句。

## 提交包里给用户的说明（pack.py 会自动生成）

- 进入哪个模式（有白膜：全能参考；只有首尾帧：首尾帧模式也可以）
- 按 `01_`、`02_`、`03_` 的顺序上传
- 模型版本（用 `--model` 传入）、时长（整数秒）、画幅
- 粘贴 `prompt.txt` 的全部内容
- 生成后把视频下载下来，命名为 `sNN_takeK.mp4`，放进 `shots/sNN/takes/`

## 模型版本的取舍

- 动作复杂、运镜要求高的镜头用较强的版本；普通镜头用便宜的版本就够。
- 较新版本写了"没有音乐"有时还会混进音乐；结尾可能突然跳到尾帧的样子；第一帧可能特别锐。
- 较便宜的 mini 版本越往后越暗、越冷，后期要按首帧校色；自带音效经常可以直接用。
