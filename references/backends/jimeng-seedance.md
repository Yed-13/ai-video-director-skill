# 后端：即梦 Seedance 2.x（网页端，用户手动生成）

- 输入：图片 ≤ 9（每张 < 30MB），视频 ≤ 3（mp4 / mov，每段 < 50MB，合计 2–15 秒），音频 ≤ 3（mp3 / wav，每段 < 15MB，合计 ≤ 15 秒），总数 ≤ 12。输出 4–15 秒，最高约 720p，自带声音。上传写实人脸会被拦截（白膜和 2D / 卡通画风不受影响）。
- 模式：首尾帧模式只能传两张图；**首尾帧 + 白膜 / 身份板 / 音频参考要用全能参考（多模态参考）模式**，在提示词里写 `@图片1 作为首帧`、`@图片2 作为尾帧`。界面会更新，和这里不一致时以界面为准，并记进 `lessons.md`。
- 引用：`@图片N`、`@视频N`、`@音频N`，按同类素材的上传顺序分别编号；每个引用都写明用途（首帧、人物外观、场景、运镜走位、动作编排、节奏、声音）。

## 从母版翻译

保留母版的【】结构，或者连成一段中文都可以。【参考】那一段写成：

```
@图片1 作为首帧，@图片2 作为尾帧，人物外观参考 @图片3，场景参考 @图片4。@视频1 只作为运镜和走位参考：参考摄影机轨迹、人物移动路线和每个动作的时间；@视频1 不是要修改的素材，不参考它的灰色材质、光影和假人外形；画风、颜色、人物外观完全以 @图片1 和 @图片2 为准。@音频1 是羊羊的声音。
```

没有的素材，就删掉对应的那一句。

## 模型版本

复杂动作和运镜用较强的版本，普通镜头用便宜的版本。已知问题见 `07-review-repair.md`。
