# 后端：即梦 Seedance 2.x（网页端，手动提交）

**模型以界面上的最新版本为准**；和这里不一致时以界面为准，并记进 `lessons.md`。

## 提交前核对四项

模型、模式、分辨率、时长。2.5 的样片模式默认 480p；正片不要停在 480p。

## Seedance 2.5（2026-11）

| 项 | 内容 | 来源 |
|---|---|---|
| 模式 | 有参考视频、身份板或音频时用「全能参考 / 多模态参考」 | 实测 |
| 提示词上限 | 15000 字 | 实测 |
| 时长 | 4–30 秒 | 官方文档 |
| 分辨率 | 样片 480p；正片 1080p 起，见到过 3840×2160 | 实测 |
| 参考素材 | 官方文档：图 ≤ 30、视频 ≤ 10、音频 ≤ 10，参考音视频合计 ≤ 30 秒；网页端可能更少 | 官方文档 |
| 画幅 | 由素材决定，可用非固定比例 | 官方文档 |
| 时间标注 | 认整数秒的区间、时间点、相对时间 | 官方文档 |
| 花费 | 15 秒一场约 195 积分（界面显示）；样片约为直出 1080p 的八分之一 | 实测 / 创作者经验 |

抽卡流程见 `gacha.md`。

## Seedance 2.0

图片 ≤ 9（每张 < 30MB），视频 ≤ 3（mp4 / mov，每段 < 50MB，合计 2–15 秒），音频 ≤ 3（mp3 / wav，每段 < 15MB，合计 ≤ 15 秒），总数 ≤ 12。输出 4–15 秒，约 720p。只认"镜头 N"，不认时间戳。

## 通用

- 上传写实人脸会被拦截（白膜和 2D、卡通画风不受影响）；人物用生成的身份板。亲密动作（拥抱等）的表演参考图也可能被拦，不硬试，改用文字和构图图。
- 首尾帧模式只能传两张图；**首尾帧 + 白膜 / 身份板 / 音频参考要用全能参考模式**，在提示词里写 `@图片1 作为首帧`、`@图片2 作为尾帧`（这种写法只保证相似，不保证和图完全一致）。
- 引用：`@图片N`、`@视频N`、`@音频N`，按同类素材的上传顺序分别编号。
- 每个引用写明**参考什么、不参考什么**，并和文字里的角色绑定："@图片2 是妈妈的长相和衣服（只参考人物，不参考背景和排版）"。素材本身够准时写"严格参考"即可，不用再描述一遍。
- 参考图里的状态和本段不同要写明："图里屏幕亮着，本段屏幕熄灭"。
- 截图当参考前，先擦掉平台的"AI"角标。
- 参考视频不能带字幕，会被继承。
- 非标准 JPG 可能上传失败，用 `ffmpeg -i in.jpg -pix_fmt yuvj420p out.jpg` 转一下。

## 从母版翻译

保留母版的【】结构即可。【参考】那一段的写法：

```
@图片1 作为首帧，@图片2 作为尾帧，人物外观参考 @图片3，场景参考 @图片4。@视频1 只作为运镜和走位参考：参考摄影机轨迹、人物移动路线和每个动作的时间；@视频1 不是要修改的素材，不参考它的灰色材质、光影和假人外形；画风、颜色、人物外观完全以 @图片1 和 @图片2 为准。@音频1 是羊羊的音色。
```

没有的素材删掉对应的那一句。接续上一场时：`本场从 @视频1 的最后一帧接着拍，@视频1 只用来接续，不是要修改的素材。`

官方的几种特殊任务写法：

| 任务 | 写法 |
|---|---|
| 关键帧参考 | 第一句写"按顺序把图片 1 到 7 作为关键帧"，后面用"然后""最后"串起来 |
| 多格分镜图 | 15 格以内，线稿或火柴人，图上不加字；提示词补全图上没有的动作和运镜；不会逐帧对齐 |
| 白模参考 | 写明参考白模视频的哪些要素（运镜、动作、灯光变化），哪个白模对应哪张图 |
| 视频延长 | 用"向后延长 @视频1：……"这类触发词；直接写 @视频1，不写"参考视频 1" |
| 视频编辑 | 用"把……改成……""去掉""加上"这类触发词，可以带时间范围，并写"其余内容不变" |

模型习惯见 `07-review-repair.md` 末节。
