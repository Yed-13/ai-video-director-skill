# 运镜写法

写提示词的【镜头】一栏时查。运镜词只是风格线索，模型不会真的模拟器材；数值（厘米、角度、秒）表达意图，不保证精确。

## 先回答六个问题

1. 摄影机从哪开始：主体前、后、侧？眼睛高度还是桌面高度？
2. 摄影机怎么走：直线前进、侧移、原地转向、小弧线？
3. 主体怎么走：不动、向前、从画面左到右、转身？
4. 两者的关系：同速保持距离，还是逐渐靠近？
5. 画面保持什么：腰部以上、产品完整、地平线水平？
6. 停在哪：什么景别、什么角度，停住还是继续？

自己在脑子里画不出这条路线，模型也画不出。先改空间关系，再改风格词。

## 一个镜头一种运镜

主体动就让机位不动，机位动就让主体不动；要两层变化时先各出一条，选好的再叠。互相矛盾的词不同时写（"固定机位"+"环绕"，"手持"+"几乎不动"）；平台的运镜预设要和文字一致。

## 词表

| 运镜 | 实际含义 | 写法要点 | 风险 |
|---|---|---|---|
| 固定 Static | 机位、朝向都不动 | 写清画面里谁在动；"固定机位，不推不拉不摇" | 仍可能微漂，后期稳定 |
| 推进 / 拉远 Dolly | 摄影机真的靠近或后退，透视变化 | "沿直线缓慢靠近，从中景停在中近景，高度不变" | 主体被"吸"过来：写"主体留在原位" |
| 变焦 Zoom | 机位不动，画面收紧 | "机位固定，缓慢变焦"；和推进二选一 | 被做成推进 |
| 摇 Pan | 原地左右转向，像转头 | "摄影机留在原位，只向右转动，停在 X 进入画面中央时" | 被做成横移 |
| 横移 Truck | 摄影机整体左右移动，有视差 | 越过前景揭示主体用它，不用摇 | 前景遮挡多时主体被重画 |
| 俯仰 Tilt | 原地抬头低头 | "摄影机本身不上升" | 和升降混 |
| 升降 Pedestal / Crane | 摄影机整体升高降低 | 写起点高度、升多少、终点 | 室内飞上天花板 |
| 跟拍 Tracking | 摄影机随主体移动 | 写从前 / 后 / 侧跟，"同速、近似距离、主体大小基本不变" | 越跟越远、绕到正面 |
| 弧线 Arc | 绕主体有限角度 | "从正前方到右前侧三分之四视角，始终看向主体中心" | 完整环绕要补造背面，结构乱 |
| 焦点转移 Rack focus | 机位不动，清晰面前后换 | 首帧要真有前后景层次 | 和"全画面清晰"矛盾 |
| 手持 Handheld | 人拿着机器的细微不稳 | "轻微、低幅度的手持漂移，构图基本稳定" | 家具被晃歪；不是通用去 AI 味开关 |
| 滑动变焦 Dolly zoom | 特殊效果，眩晕、震惊 | 只在需要这种情绪时用 | 极不稳定 |

稳定器词（Steadicam、Gimbal）说的是稳定方式，不是方向：`斯坦尼康式稳定跟拍，摄影机在人物身后同速前进，肩部高度，人物在画面中央偏右`。

## 左右和方向

左右一律按画面写（"从画面左侧走向右侧"）；环绕写"从正前方转到人物的右前侧"，不写顺时针 / 逆时针。背影画面里，画面左侧就是人物的左手。

## 按目的挑

| 目的 | 起步用 |
|---|---|
| 看清按键、屏幕、表情 | 固定机位 |
| 表现材质和外形 | 短距离推进或小弧线 |
| 交代人与物、人与人的关系 | 固定中景，或从近景拉远揭示 |
| 跟人进入空间 | 身后稳定跟拍；不稳就改固定机位让人入画 |
| 看行走中的表情 | 正面退拍 |
| 介绍房间 | 缓慢摇 |
| 从细节转到反应 | 焦点转移，或直接切 |
| 惊慌、冲突 | 克制手持 |

动画有自己的惯例（平移背景代替真 3D 运镜等），见 `styles/` 里对应风格。

## 常见失败

| 现象 | 改法 |
|---|---|
| 镜头穿过家具、室内乱飞 | 写可走的路线（"沿桌前空地横移"），或固定机位分两镜 |
| 产品自己转，摄影机没动 | "产品静止，摄影机沿弧线移动"；检查有没有套转台预设 |
| 跟拍变追赶 | 加"相同步速、近似距离、人物大小基本不变" |
| 侧面跟拍绕到正面 | 写终点："整段保持侧面视角" |
| 地平线歪、背景扭 | 只留一种运动；换更清楚的首帧 |
| 莫名切镜 | 写"一个连续镜头"；检查有没有"随后特写"这类隐含切镜的话 |
