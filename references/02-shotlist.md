# 阶段 2：机位、分镜、光色

前期最重要的一步：镜头设计平淡，片子就平淡；构图和配色往往比剧情更影响成片。有参考片时先 `clip.py stills <参考片> --every 0.5` 抽帧，量出机位、景别、进出画位置和镜头时长，再模仿。

## 顺序

1. 每场戏画机位图（`camera-blocking.md`）：`blocking/<场景>.json` → `floorplan.py`，处理越轴和左右对调的警告。
2. 写分镜表和生成段。
3. 写光色表、色彩剧本（`light-color.md`）。
4. 画色块草图总表。
5. 一起交给用户确认。

## 分镜表字段

| 字段 | 写什么 |
|---|---|
| 片中时间 | 起止时间；配歌按小节 |
| 生成秒数 | 片中时长 + 约 0.5 秒余量，向上取整到整数秒，4–15 秒 |
| 景别 / 机位 | 景别；机位图编号和类型（"5 号外反拍，过 B 肩看 A"）；高度和角度 |
| 画面左右 | 从机位图表里抄：每人在画面左 / 中 / 右（百分比），视线朝哪侧 |
| 运镜 | 类型、幅度、速度 |
| 走位 | 谁从画面哪侧进、往哪侧走、停在哪 |
| 表情推进 | 靠什么表情变化讲故事 |
| 什么在动 | 摄影机 / 焦点 / 光 / 前景物 / 小动作，至少一项 |
| 光色 | 属于光色表哪一场；主光在画面哪侧 |
| 转场 / 生成段 | 怎么接下一镜；和哪几镜合在一起生成 |

## 镜头设计

1. 全片平视正面最多两次，其余用俯、仰、背后、过肩、透过前景拍。
2. 画面里一直有东西在动：人或物进出画；人不动就让别的动（飘过的纸、身后的路人）。该静的地方要静，才有对比。
3. 运镜要有理由：跟着人或物走、慢慢推近给特写、从近处拉远交代环境。
4. 人的头或眼睛放在画面横向约 38% 或 62% 处，任何一秒截图都要好看。

有台词、有情绪变化的戏按这几条切：
- 换人说话就切（说话的人 → 听的人的反应 → 说话的人；长台词中途也切，台词不断）；
- 情绪变一次给一个镜头；
- 大动作拆成准备 → 执行 → 结果；
- 换场景、跳时间必须切，留 1–2 秒转场；
- 不连续 3 个镜头用同一景别。

参考时长：远景 / 全景 3–4 秒，中景和近景 2–3 秒，反应约 1 秒，高潮 3–5 秒，单镜不超过 10 秒；台词约每 10 字 2 秒。

## 生成段

| 做法 | 适合 | 控制方式 |
|---|---|---|
| 一镜一段 | 动作、复杂运镜、要精确起止画面 | 首尾帧 + 白膜 |
| 多镜一段（连续 2–4 镜，5–15 秒） | 对话、正反打、反应 | 提示词按镜头写切点；喂身份板、场景图、站位大全景 |

分镜表后列出生成段，如"生成段 3：镜头 7–9，对话，多镜一段，10 秒"。另外给每个主要角色规划几段 3–5 秒、不说话、只做表情的**反应镜头**（惊讶、怀疑、憋笑、愤怒），剪长台词时盖在说话画面上。

## 光色表与色块草图

- 配色和光线在画第一张图之前定好，不交给模型自由发挥。问用户偏好；没想好就给 2–3 套方案让用户选。`palette.md` 的格式见 `light-color.md` 第 1 节：每场戏的光色表，加上强调色留给谁。
- 色块草图：用代码给每个镜头画 1920×1080 的色块图（人物、主要物体、背景，标出 38% / 62% 竖线），拼成总表。`frames.py gray` 转黑白后人和背景分不开，说明明暗对比不够，回去调配色。
