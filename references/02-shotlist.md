# 阶段 2：分镜与配色

这是前期最重要的一步。故事再好，镜头设计平淡，片子也会平淡。构图和配色对成片质量的影响往往比剧情还大。

## 有参考片时

先逐帧看参考片：用 `scripts/clip.py stills <参考片> --every 0.5` 抽帧，量出每个镜头的机位、景别、人物进出画面的位置和比例、镜头时长，再学习和模仿。

## 先画机位图

写分镜表之前，先给每一场戏画俯视机位平面图（规则、九个标准机位和脚本用法都在 `camera-blocking.md`）：

1. 写 `blocking/<场景>.json`：人物的位置和朝向、轴线、主要道具，以及这场戏每个镜头的机位（id 用镜头编号，按分镜顺序排列）。
2. 运行 `python3 scripts/floorplan.py blocking/<场景>.json`，得到机位图和"画面左右"表。
3. 有越轴或左右对调的警告，就调整机位，或者写明合理的越轴办法并标 `"cross": true`。
4. 机位图和分镜表一起交给用户确认。

## 分镜表的字段

`shotlist.md` 每个镜头一行（或一节），必须写清：

| 字段 | 说明 |
|---|---|
| 片中时间 | 在成片里的起止时间；配歌就按小节写 |
| 生成秒数 | 片中时长加约 0.5 秒余量（后期好剪），再向上取整到**整数秒**；至少 4 秒，最多 15 秒 |
| 景别 | 远景 / 全景 / 中景 / 中近景 / 特写 / 大特写 |
| 机位 | 机位图里的位置和类型（如"5 号外反拍，过 B 肩看 A""8 号骑轴"），以及高度和角度：平视、俯拍、仰拍、背后、过肩、透过前景物体拍 |
| 画面左右 | 从机位图的表里抄：每个人在画面左 / 中 / 右（附百分比），视线朝画面哪一侧 |
| 运镜 | 推、拉、摇、移、升降、环绕、跟拍、固定；写幅度和速度 |
| 走位 | 谁从**画面哪一侧**进来、往哪一侧走、停在哪里 |
| 表情推进 | 这个镜头靠什么表情变化讲故事 |
| 什么在动 | 摄影机 / 焦点 / 光 / 前景飘过的东西 / 人物小动作，至少一项 |
| 转场 | 怎么接到下一个镜头 |

## 镜头设计规则

1. **每个镜头换角度**。全片平视正面最多出现两次，其余用俯拍、仰拍、背后、过肩、透过东西拍。
2. **画面里要一直有东西在动**。大多数镜头里，要有人或物从画外进来，或者走出画外。人不走动时，就让别的东西动：飘过的纸、身后经过的路人。固定机位更需要人在画面里移动，比如从远处走到近处。
3. **景别要轮换**。不要连续几个镜头都是全身，全景、中景、特写要交替。
4. **写清楚动的是什么**。写每个镜头前先问：这个镜头里到底什么在动？一项都写不出来，说明这个镜头还没想好。但也不是越动越好：该动的地方动，该静的地方静，才有对比。
5. **运镜要有理由**。最常用的三种：跟着一个人或物走；慢慢推近给特写；从近处慢慢拉远交代环境。
6. **每一秒截图都要好看**。人的头或眼睛放在画面横向约 38% 或 62% 的位置，不放在正中间。

## 配色

配色不交给模型自由发挥，在画第一张图之前就定好。

1. 问用户的偏好；用户没想好，就给 2–3 套方案让他选。
2. 写 `palette.md`：全片的主色、辅色、强调色（色值），以及**每一场用什么颜色**的色表。
3. 写明强调色留给什么（比如只有主角的围巾是红色）。

## 色块草图总表

用代码（Python + Pillow，或者让 Codex 写）给每个镜头画一张 1920×1080 的色块草图：用色块表示人物、主要物体和背景，标出 38% 和 62% 的竖线。全部拼成一张总表给用户确认。

然后转成黑白再看一遍：`python3 scripts/frames.py gray 草图总表.png`。如果转黑白后人和背景分不开，说明明暗对比不够，要回去调配色。
