# 阶段 8：后期与交付

全部用代码完成（ffmpeg + Python）。所有中间文件放在 `post/`。

## 基本规则

- **色彩空间**：Seedance 输出的 mp4 通常没有标注色彩空间，按 BT.601 解码；H3 输出先用 `ffprobe` 看标注。中间文件用无损格式（PNG 序列，或 `-c:v ffv1`）。最终交付标注 BT.709。
- **只改标注不够，要真的转换**：没有标注的源文件，在第一步处理时就加 `scale=in_color_matrix=bt601:out_color_matrix=bt709`，把 YUV 数据从 601 转成 709。只在最后加 bt709 标签、不做转换的话，播放器显示的颜色会偏。
- **不覆盖**：每一步输出新文件，比如 `s03_trim.mov`、`s03_grade.mov`。
- **抽查切点**：每个剪辑点前后各抽 3 帧检查。

## 常用操作

剪掉开头和结尾（精确到帧，重新编码到无损中间格式）：

```bash
ffmpeg -i s03_take2.mp4 -vf "trim=start_frame=1:end_frame=140,setpts=PTS-STARTPTS,scale=in_color_matrix=bt601:out_color_matrix=bt709" -an -c:v ffv1 post/s03_trim.mkv
```

（`end_frame=140` 表示保留到第 139 帧为止，帧号从 0 开始。）

结尾跳变时，停在最后一张好的帧上（下面的例子停在第 129 帧，也就是 `end_frame` 减 1，再补 0.5 秒）：

```bash
ffmpeg -i in.mp4 -vf "trim=end_frame=130,setpts=PTS-STARTPTS,tpad=stop_mode=clone:stop_duration=0.5" -an -c:v ffv1 post/s03_hold.mkv
```

720p / 768p 放大到 1080p，加轻微锐化：

```bash
ffmpeg -i in.mkv -vf "scale=-2:1080:flags=lanczos,unsharp=5:5:0.4" -c:v ffv1 out.mkv
```

最终交付编码（标注 BT.709）：

```bash
ffmpeg -i final.mkv -i music.wav -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p \
  -colorspace bt709 -color_primaries bt709 -color_trc bt709 -c:a aac -b:a 256k -shortest final.mp4
```

`-shortest` 会按画面和音乐里较短的那个截断。音乐比画面短时，先把音乐补长或调整剪辑，不然片尾会被剪掉。

## 转场

用户指定哪一镜接哪一镜、用什么转场（硬切、用前景物体盖屏带过、甩镜）。甩镜和盖屏转场要加运动模糊：把转场段内插成 8–16 个子帧再混合，模拟半帧快门（180°）。不要对整段视频做插帧。

## 对白戏：声音不断，画面切到听的人

生成出来的一段从头到尾都对着说话的人时，在剪辑里补：

1. 把说话那段的声音分离出来，留在原位，一直不断；
2. 在上面一层盖 1–2 秒"听的人"的反应镜头（来自反应镜头库，见 `02-shotlist.md`）；
3. 观众看到的是前半句看着说话的人，后半句切到别人的反应，声音一直连续。

ffmpeg 做法：用 `overlay` 在指定时间段把反应镜头盖在说话镜头上，音轨只取说话镜头的。

## 调色

原理、风格配方和 ffmpeg 调色积木见 `light-color.md`。

1. **先统一（校正）**：每场戏选一张定稿的样帧或首帧作为基准，`python3 scripts/look.py compare <基准> <这场戏的所有片段>`，按给出的校正参数把每个片段的色温、亮度、饱和度、色偏调到和基准一致，再量一次确认。
2. **再风格化**：全片用同一套风格参数（青橙、提黑、LUT 等），按故事分段时每段对照光色表。
3. **最后加质感**：颗粒、暗角统一在最后加（除非用户不要）。
- 只调饱和度和亮度时不动色相；强调色受保护；肤色不变。
- 漂移修正：用 `clip.py inspect` 生成的 `drift.csv`，以首帧的数值为目标逐段校正。

## 声音：对白、音效、配乐分三层

- **对白**最大，观众必须听清；**音效**其次，跟着画面走；**配乐**最小，有人说话时再压低（侧链压缩或音量关键帧）。
- 配乐统一在后期加一首。每段都让模型配乐的话，几十段接起来调性会乱，所以提示词里写"不要背景音乐"。
- 视频自带的声音要先查：可能混着乱语和模型自己生成的背景音乐。需要保留的台词用 Demucs 分离出人声；其余静音，底噪用干净的环境声代替。
- 全片响度统一（例如 `loudnorm=I=-16:TP=-1.5:LRA=11`）。
- 拍点只在**原曲**上测，不在剪过的文件上测。关键动作对重拍，转折对副歌。
- 用文生音乐做纯器乐时，生成后用语音识别扫一遍，确认没有把提示词唱出来。

## 字幕

- 模型画出来的字经常是错字，所以字幕在后期加，提示词里写"不要字幕"。
- 用语音识别（如 Whisper / SenseVoice）出时间轴，再拿剧本台词逐句对齐、核对。模型念的台词偶尔和剧本差一两个字：要么重新生成这一段，要么把字幕改成实际念的，**字幕必须和声音一致**。
- 放在画面下方三分之一，别挡脸，一行别太长；内心独白换个颜色或加括号。
- 烧字幕：`subtitles=subs.ass`，但需要 ffmpeg 编译时带 libass（先用 `ffmpeg -h filter=subtitles` 检查；Homebrew 默认的 ffmpeg 可能没有）。没有的话，交付 `.srt` 另外上传，或者用剪映等剪辑软件加字幕。

## 剪辑单

素材都出来后，先写一份 `post/edit_list.md` 再动手剪：
1. 按剧情顺序排好素材，标出每段保留第几秒到第几秒、头尾各剪掉多少；
2. 标出长台词处在第几秒盖哪段反应镜头、盖多长；
3. 列出还缺的补拍镜头；
4. 配乐分段（情绪、起止时间，有台词处标"压低"）；
5. 全部字幕，和剧本逐字核对，标明是"说""内心独白"还是"画外音"；
6. 检查开头 3 秒有没有冲突、结尾是不是停在悬念上。
