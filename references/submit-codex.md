# 交给别人提交：任务书

用户不想自己在网页上点、又不走 API 时，把提交交给能操作浏览器的 agent（Codex App、Claude in Chrome 扩展等）。你写任务书，对方只负责上传、粘贴、生成、下载。

## 规矩

- **每轮任务书只列已经齐备的素材。** 要等上一场成片才能做的素材（接续用的尾片）放到下一轮；列进同一份，对方会因为"素材不全"停下。
- 前置依赖由你处理：上一场回来后你截尾片（`scene.py tail`）、看片、改下一场的提示词，再发下一轮。
- 提示词存成文件，让对方全文原样粘贴，并核对末尾一句，防截断。
- 写明"立即停下"的情况。充值、会员、付款、新条款一律不点。
- 新 take 存新文件名，不覆盖。

## 任务书模板

```markdown
# 《片名》第 N 轮：<场 A>、<场 D>

素材文件夹：<绝对路径>
成片保存文件夹：<绝对路径>（存成 <场>_take<K>.mp4，不覆盖已有文件）

## 通用设置
1. <平台> 视频生成，模型 **<模型名>**（不要换成别的版本），模式「<全能参考>」。
2. 画幅 <16:9>；时长按每场写的秒数（每场都核对时长控件）；分辨率 <选项>。
3. 按下表顺序上传图片，依次成为 @图片1、@图片2……；再上传视频、音频；上传后核对缩略图顺序。
4. 打开这一场的 prompt.txt，全文原样粘贴，不改字；粘完核对末尾一句是「<末句>」。
5. 生成；完成后下载，保存到成片文件夹。
6. 记下消耗的积分。

本轮只提交 <A、D>，素材都齐。其余场次下一轮再做，本轮不用管。

## 立即停下汇报
- 模型没有这个模式、不能上传视频或音频、选不到这个时长、图片数不够：停下告诉我，不换模型。
- 积分不足、充值、会员、付款页面：不点。
- 上传被拦截：截图，说明哪场哪个文件。
- 提示词被截断或超字数：说明哪场、上限多少，不要删改。
- 生成失败：重试一次，再失败记下错误跳过。
- 不改账号设置，不接受新条款。

## <场 A>　15 秒（无视频、无音频）
1. A_01_首帧.png
2. A_02_身份板_某某.png
- 提示词：A_prompt.txt
- 保存为：<路径>/A_take2.mp4

## 做完汇报
每场：成功 / 失败、保存路径、消耗积分；最后剩余积分。
```

## 给用户粘贴的那段话

```
请按 <任务书绝对路径> 执行第 N 轮提交。只做任务书里列的场次，遇到"立即停下汇报"里的情况就停，做完按"做完汇报"回复。
```

抽卡时在任务书里写清每场出几条、文件名怎么编（`A_take2a.mp4`、`A_take2b.mp4`），见 `gacha.md`。
