# 机位与轴线

阶段 2 给每场戏画俯视机位平面图，分镜表里每个镜头写明用哪个机位。AI 本来就容易左右混乱，没有机位图，正反打和走位方向很容易对不上。

## 轴线（180° 规则）

- 两人互动按**关系轴线**（两人连线），移动按**运动轴线**（运动方向）。同一场戏所有机位在轴线同一侧：A 始终在左、B 始终在右；人往右走就一直往右；往右出画，下一镜从左入画。
- 合理越轴的办法：镜头运动中跨过去、人物走动建立新轴线、先切骑轴镜头（8、9 号）过渡、插空镜或特写、人物视线转向新对象。在分镜表写明用哪种，机位图里标 `"cross": true`。
- 三人以上：用这场戏的主要关系当轴线，关系变了重画；配角尽量站成一组。

## 两人对话九机位

A 在左、B 在右，所有机位在轴线同一侧。示意图：`references/img/two-person-dialogue.png`（模板 `templates/two-person-dialogue.json`）。

| 编号 | 名称 | 拍到 | AI 生成时 |
|---|---|---|---|
| 1 | 总角度 | 两人侧面 | 一场戏的第一镜，建立左右关系，后面都以它为准 |
| 2、3 | 平行机位 | 单人侧面 | 好生成，但看不清表情 |
| 4、5 | 外反拍（过肩） | 前景一人的肩和后脑 + 另一人的脸 | **最容易出错**：两人长相混淆、前景的人突然转身。写死"前景是 B 的右肩和后脑，虚化，始终背对镜头" |
| 6、7 | 内反拍 | 单人 3/4 正面，看向画外的对方 | **对 AI 最友好**。写明视线朝向："看向画面右侧镜头外" |
| 8、9 | 骑轴 / 主观 | 单人正面直视镜头 | 正脸最容易保持一致；压迫感强，少用；可做越轴过渡 |

视线规则：A 的单人镜头视线朝画面右，B 的朝画面左；正反打两边景别和机位高度对称。常见切法：1 → 5 → 4 → 7/6 → 1。为降低抽卡率，少用过肩，多用内反拍，用剪辑建立关系。

## 机位图：`floorplan.py`

每场戏写 `blocking/<场景>.json`（单位米，俯视 x 向右、y 向下）：

```json
{
  "scene": "公园长椅", "size": [10, 6],
  "characters": [
    {"id": "A", "name": "女孩", "pos": [3, 2.5], "faces": "B"},
    {"id": "B", "name": "男孩", "pos": [7, 2.5], "faces": "A"}
  ],
  "axis": ["A", "B"],
  "props": [{"name": "长椅", "rect": [2, 2.8, 6, 0.5]}],
  "cameras": [
    {"id": "s01", "pos": [5, 5.5], "aim": [5, 2.5], "fov": 55, "note": "1 总角度"},
    {"id": "s02", "pos": [8.2, 3.3], "aim": "A", "fov": 35, "note": "5 外反拍，过 B 肩看 A"}
  ]
}
```

- `faces` / `aim` 写人物 id 或坐标；`fov` 是水平视角（广角约 70，标准约 45，长焦约 25）。
- 镜头 id 用分镜编号，按分镜顺序排列；有意越轴的加 `"cross": true`。

`python3 scripts/floorplan.py blocking/<场景>.json` 输出机位图（PNG，没有 Pillow 时输出 SVG），并打印每个镜头在轴线哪一侧、每个人在画面左 / 中 / 右的位置（附百分比），以及越轴和左右对调的警告。这张"画面左右"表用来写首尾帧和视频提示词里的站位，也用来摆白膜的摄影机。
