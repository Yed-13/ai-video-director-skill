# 机位与轴线

分镜阶段（阶段 2）给**每一场戏**画一张俯视的机位平面图，标出人物、朝向、轴线和每个镜头的机位。分镜表里每个镜头都要写明它用的是哪个机位。没有机位图，前后镜头的左右关系、视线方向很容易对不上，AI 生成后才发现"人物位置跳了"，那时候就晚了。

## 1. 轴线（180° 规则）

- **关系轴线**：两个人对话或互动时，两人之间连一条线。
- **运动轴线**：一个人或一辆车在移动时，沿着它的运动方向画一条线。
- **规则**：同一场戏里，所有机位都放在轴线的**同一侧**（180° 范围内）。这样，A 始终在画面左边、B 始终在画面右边；A 往右看，B 往左看；人往画面右侧走就一直往右走。
- **越轴**：摄影机跑到了轴线另一侧，切过去以后两人左右对调，观众会觉得人物"瞬移"了。AI 视频本来就容易左右混乱，越轴会让这种问题更严重。

### 可以合理越轴的几种办法

1. **镜头内越轴**：一个镜头里摄影机移动着跨过轴线，观众能看到过程。
2. **人物移动**：人物在画面里走动，建立了新的轴线。
3. **骑轴镜头过渡**：先切一个正好在轴线上的镜头（第 3 节里的 8、9 号机位），再切到另一侧。
4. **插入镜头**：中间插一个空镜、特写或别处的反应镜头，把观众的空间记忆打断。
5. **视线转移**：人物转头看向新的对象，新的视线就是新的轴线。

需要越轴时，在分镜表里写明用的是哪种办法。机位图里把这个镜头标成 `"cross": true`，脚本就不会报警。

## 2. 机位高度与角度

| 机位 | 效果 | 提示词写法（中文 / H3 英文） |
|---|---|---|
| 平视 | 中性、客观 | 平视机位 / eye-level |
| 俯拍 | 人物显得弱小、被压迫 | 俯拍，从高处向下 / high angle |
| 顶拍 | 交代空间关系，带抽离感 | 正上方垂直向下 / top-down overhead |
| 仰拍 | 人物显得高大、有力量 | 低机位仰拍 / low angle |
| 斜角（荷兰角） | 不安、失衡 | 画面倾斜 15° / dutch angle |
| 背后 / 过肩 | 带观众进入人物的处境 | 从背后拍 / from behind, over the shoulder |

注意：俯拍容易拍不到脸，AI 也容易把脸画坏。要表现情绪的镜头尽量别用大角度俯拍。

## 3. 两人对话的九个标准机位（三角形原理）

两人面对面，A 在左、B 在右，轴线连接两人。所有机位都在轴线同一侧（下图中轴线的下方）：

```
          （轴线另一侧：不放机位）
  ·· A ▷ ··· [8]◁ ········ ▷[9] ··· ◁ B ··  ← 轴线
 [4]↗     [6]↖           ↗[7]     ↖[5]
      [2]↑                     ↑[3]
                   [1]↑
```

用 `scripts/floorplan.py` 渲染 `templates/two-person-dialogue.json`，可以得到这张图的正式版本（`references/img/two-person-dialogue.png`）。

| 编号 | 名称 | 拍到什么 | 用途 | AI 生成时要注意 |
|---|---|---|---|---|
| 1 | 总角度 / 关系镜头 | 两人都在画面里，侧面 | 交代两人的位置关系；一场戏的第一个镜头 | 两人都要在首帧里摆好位置。A 在左、B 在右，后面所有镜头都以这个为准 |
| 2、3 | 平行机位 | 单人，侧面 | 节奏平稳的单人镜头 | 侧脸看不清表情；适合动作，不适合表现情绪 |
| 4、5 | 外反拍（过肩） | 前景是一个人的肩膀和后脑，后面是另一个人的脸 | 对话中最常用；同时交代两人的关系 | **AI 最容易出错**：两个人重叠，容易长相混淆，前景的人会突然转身。提示词写死："前景是 A 的右肩和后脑，虚化，只露背面，始终不转身" |
| 6、7 | 内反拍 | 单人，3/4 正面，看向画面外的对方 | 情绪、反应镜头 | **对 AI 最友好**：画面里只有一个人，脸清楚。写明视线方向："视线看向画面右侧镜头外" |
| 8、9 | 骑轴 / 主观机位 | 单人，正面，直视镜头 | 代入对方视角，压迫感强；也可以用作越轴的过渡镜头 | 正脸最容易保持人物一致；但直视镜头会显得很强烈，不要多用 |

**视线规则**：A 在左时，A 的单人镜头里视线朝画面**右侧**；B 的单人镜头里视线朝画面**左侧**。正反打（A 和 B 的镜头来回切）时，两个镜头的景别和机位高度要对称。

### 一场对话的常见切法

1（交代关系）→ 5（过肩看 A）→ 4（过肩看 B）→ 7 或 6（反应特写）→ 回到 1 或换一个新的总角度。

为了降低 AI 抽卡率，可以少用 4、5 号过肩镜头，多用 6、7 号内反拍，用剪辑来建立两人的关系。

## 4. 三人及以上

- 先找出这场戏的**主要关系**，用它作为轴线；人物之间的关系变了，就重新画轴线。
- 三人呈三角形站位时，可以把 1 号总角度放在三角形的开口一侧，每个人的单人镜头都从这一侧拍。
- 配角越多，AI 越容易出错（见 `01-story.md`）。尽量让配角站在一起、作为一个整体。

## 5. 运动镜头与运动轴线

- 人物往画面右侧走，就在后面每个镜头里都往右走。要改方向，必须拍到他转身，或者插入一个正面 / 背面的镜头（迎面走来或背影走远）作为过渡。
- 跟拍时摄影机在运动轴线的哪一侧，就一直在那一侧。
- 从画面一侧出画，下一个镜头就从另一侧入画（往右出画，就从左边入画）。

## 6. 机位平面图怎么做

每一场戏写一个 JSON 文件，放进 `blocking/<场景>.json`。格式见 `templates/two-person-dialogue.json`：

```json
{
  "scene": "公园长椅",
  "size": [10, 6],
  "characters": [
    {"id": "A", "name": "女孩", "pos": [3, 2.5], "faces": "B"},
    {"id": "B", "name": "男孩", "pos": [7, 2.5], "faces": "A"}
  ],
  "axis": ["A", "B"],
  "props": [{"name": "长椅", "rect": [2, 2.8, 6, 0.5]}],
  "cameras": [
    {"id": "s01", "pos": [5, 5.5], "aim": [5, 2.5], "fov": 55, "note": "1 总角度，全景"},
    {"id": "s02", "pos": [8.2, 3.3], "aim": "A", "fov": 35, "note": "5 外反拍，过 B 肩看 A"}
  ]
}
```

- 坐标单位是米。俯视图里 x 向右、y 向下。
- `faces` / `aim` 可以写一个人物的 id，也可以写一个坐标点。
- `fov` 是水平视角（度）：广角约 70，标准约 45，长焦约 25。
- 镜头 id 直接用分镜表里的镜头编号（s01、s02……），按分镜顺序排列，脚本才能检查相邻镜头。
- 需要合理越轴的镜头加 `"cross": true`。

运行：

```bash
python3 scripts/floorplan.py blocking/公园长椅.json
```

输出：

- `blocking/公园长椅.png`（或 `.svg`）：俯视机位图，包括人物、朝向、轴线、每个机位的视角范围和镜头编号。
- 终端里打印一张表：每个镜头在轴线的哪一侧，每个人物出现在画面左边、中间还是右边，以及是否在视角范围内。
- 检查结果：相邻两个镜头位于轴线两侧（越轴）、或者两个人在画面中的左右顺序对调时，会给出警告。

这张"画面左右"表直接用来写首尾帧提示词和视频提示词里的"谁在画面左侧 / 右侧"，也作为白膜里摄影机摆放的依据（见 `05-greybox.md`）。
