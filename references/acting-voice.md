# 表演与台词写法

有人物表演或台词的段落，写视频提示词前读。目标是去掉两种"AI 味"：匀速、像朗读的声音；匀速、做完就定格的动作。

## 给模型处境，不给形容词

只写走位（坐着、看着）和形容词（很轻、很慢、带鼻音），模型不知道人物是谁、刚发生了什么，只能演出"标准答案"。每段都当成独立的新场景，写三样：

```
【前情】她是谁，之前发生了什么。写明"以上发生在这场之前，只作为背景，不在画面和声音里出现"。
【这场戏】此刻在哪、为什么来。
【她此刻】心里想的和不说出口的（潜台词），身体因此是什么状态。
```

## 表演

- 情绪写成肌肉和呼吸，按"触发 → 发酵 → 释放"：隐忍的哭写"喉咙滚动一下，下唇内侧咬住，眼眶红但泪不落"，不写"她很难过"。
- 按先后顺序写看得见的细节：重心、手、呼吸、眼皮、嘴角、视线落点；有犹豫、有停半拍、速度不匀。
- **细和多是两回事。** 细是速度、停顿、手、视线、呼吸、哪里不动，要多写；多是动作的数量，要少。用户说"不够细"时加前者，不加动作。
- 每个镜头只有一个主要动作。全片加一段动作幅度句（写实片）：
  `像纪录片里偷拍到的普通人：每个镜头只有一个主要动作，其余时间只有呼吸、眨眼和很小的视线变化；人物从不看镜头。`
- 台词之间插一个看得见的小动作（出一口气、肩膀一耸），停顿就有了着落。
- 安静写成正向状态："她闭着嘴在听"。只写"不说话"，模型会自己补台词。
- 走路最容易假：尽量不拍，用固定机位让人物入画或出画；要拍就只拍腰部以上。
- 手和物体接触的难动作交给首帧（`04-keyframes.md`），或拆成两个镜头。
- 写不出来的表演：让用户用手机自己演一遍，当动作参考视频。

动画片的表演相反（要夸张、要预备动作和停顿帧），见 `styles/` 里对应风格。

## 台词

- **对白不写逐秒时间戳。** 时间戳会被当成"说话窗口"，台词提前说完，模型就编耳语来填空。只写顺序和停顿；镜头可以标"约 a–b 秒"。精确对时放到剪辑。
- 一句一句写，每句写怎么说：语速、哪个字慢、句尾往上还是往下、说之前有什么动作。
- 用标点控制语气：`……` 声断气连，`——` 拖音，`？` 尾音上扬，`！` 一句最多一个；一句里逗号最多一两个。
- 每个镜头一个说话人。时长按每 10 字约 2 秒估，逐镜加总，最后留 1.5–2 秒交接停顿。

## 发声一致

同一个人整场只用**一段**发声描述，每场原样复制：

```
38 岁女声，普通话，音色偏中低、略沙。每一句都用同一种发声方式：正常出声，音量比平时小一点，
近距离收音的干声，没有混响；句与句之间只有语速和停顿不同。像手机在家里录到的真人说话，
不是配音、不是播音腔，字和字之间不等距。不说话时闭着嘴，只有呼吸。
```

禁用词（会让同一个人一会儿悄悄话、一会儿正常）：耳语、气声、声音更小、像说给自己听、悄悄。

## 口型

口型和微表情是模型最弱的地方。情绪戏优先让说话人的嘴不入画：过肩、逆光侧脸剪影、背影广角、背后望窗。这样声音可以后期整条换成真人录音或重新配音。必须拍正脸说话时加克制句："口型自然，嘴不过度张开，说话时不转头"。
