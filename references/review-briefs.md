# 审核 agent 任务书

每次审核另开一个子 agent，只给列出的材料，不给你的结论和对话。把任务书原样发过去，方括号换成实际路径。审核 agent 可以用 `scripts/` 里的工具（如 `frames.py onion`、`frames.py phone`）。

## 1. 故事审核（阶段 1）

材料：[story.md]

```
这是一支短片的逐镜头故事。你是第一次看，只挑错，不改文件。
1. 按镜头顺序读完，先用自己的话复述你看懂的故事。
2. 逐个转折追问：为什么会这样？东西从哪来？够得着吗？现实里真会这样吗？
3. 能用一句话说清想表达什么吗？和文件开头那句一致吗？
4. 开头几秒抓人吗？
5. 旁人的反应像真人吗？有先后吗？有没有几个人同一秒做同一个动作？
6. 哪些镜头 AI 视频模型容易拍错：人物交叉、手拿小东西、文字、镜子和倒影、左右不对称的特征、一个镜头里换光、一个人连做三个动作、俯拍看不到脸、配角太多？
7. 心理活动有没有写成拍不到的文字？台词有没有区分说、内心独白、画外音？
每条写：镜头、问题、建议改法，没把握的写"可能"。最后写"通过"或"不通过"。
```

## 2. 首尾帧审核（阶段 4：画之前审文字，画之后审图）

材料：[首帧 / 尾帧的文字说明或图片]、[设定图]、[该镜头的分镜]、[这场戏的光色表和机位图画面左右表]

```
你是审核，只读不改。每张图都放大看。
1. 动作要用到的东西，首帧里都有吗？
2. 别人的反应提前摆好了吗（做事的人在前，反应的人在后、脸朝镜头）？
3. 多人有没有摆成同一个姿势？
4. 东西要落到、飘到的地方空出来了吗？人头顶留空了吗？
5. 风向统一吗？
6. 缩到手机大小（frames.py phone）还看得清主要人物吗？
7. 有没有多余的东西、奇怪的线、多出来的手指？
8. 首尾帧叠起来（frames.py onion）看，不该变的地方（墙色、家具位置、物体大小）完全一样吗？
9. 和设定图对得上吗（服装、发型、不对称特征在哪侧）？光的方向和冷暖符合光色表吗？
10. 人物左右、视线方向、前后景和机位图的画面左右表一致吗？过肩镜头前景只露肩和后脑吗？
每条写：图、位置、问题、建议改法。最后写"通过"或"不通过"。
```

## 3. 提交前审核（阶段 6，每段生成前必做）

材料：[prompt_master.md]、[后端格式的提示词]、[pack/ 全部文件]、[greybox_first.png、greybox_last.png（有白膜时）]、[机位图 png 和画面左右表]、[设定图]、[分镜表里这几个镜头]、[光色表里这场戏]、[前后段的首尾帧]

```
你是审核，只读不改。这一段马上要提交生成，要花真钱或大量时间。图片放大看。
1. 提示词每句话和图片对得上吗：位置、左右、颜色、人数、道具数量、衣服、表情？
2. 首尾帧机位、尺寸、背景一致吗？白膜首末帧和首尾帧的构图对得上吗？
3. 和设定图、前后段、机位图（人物左右、视线、前后景）对得上吗？光色句和光色表一字不差吗，光的方向和冷暖和首尾帧一致吗？
4. 动作现实吗？每个动作的原因、手放在哪写了吗？动作接上了上一段的结尾吗？
5. 模型可能在哪出错：同时动作、凭空出现、物体长脸、走反方向、歧义词、数量变化？
6. 台词：一字不差吗？说 / 内心独白 / 画外音分开写了吗？每句有语气吗？时长放得下吗（约每 10 字 2 秒）？
7. 参考素材：每个都写明用途了吗？场景图只有一张吗？引用编号和 pack/README.txt 的上传顺序一一对应吗？
8. H3：字段名和顺序对吗，标签前后一致吗，结构化部分是英文吗，切点时间在时长内吗？
9. 时长和动作量匹配吗？
最后只写"通过"或"不通过"；不通过就逐条列出要改什么。
```

## 4. 全片复核（阶段 8）

材料：[成片路径]

```
这是一支短片的成片。你第一次看，我不告诉你任何结论。
1. 用 ffmpeg 解码。每个镜头取多张全分辨率帧；找出切点，切点前后各取 3 帧。
2. 先写你看懂的故事，再列看不懂的地方。
3. 逐镜查：重复动作、道具数量变化、穿帮、突跳、颜色跳变、脸变形、同一人出现两次、场景矛盾、字幕和文字问题。
4. 写明你查不了的东西（动作流畅感、声音）。
每条写：时间、帧号、问题，分"硬伤"和"小问题"。最后写"通过"（没有硬伤）或"不通过"。
```
