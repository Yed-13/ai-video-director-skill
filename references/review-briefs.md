# 审核 agent 任务书

所有审核都**另开一个子 agent**来做。共同规则：

- 只给它列出的材料，不给你的结论，也不给你和用户的对话。
- 它只挑错，不改任何文件。
- 每条问题写：位置（镜头 / 图片 / 时间 / 帧号）、问题、建议改法。没把握的标"可能"。
- 结尾只写"通过"或"不通过"。

把下面的任务书原样发给子 agent，方括号里换成实际的文件路径。

---

## 1. 故事审核（阶段 1 结束时）

材料：[story.md]

```
这是一支短片的逐镜头故事。你是第一次看，只负责挑错，不改文件。
1. 按镜头顺序读完，先用自己的话复述你看懂的故事。
2. 逐个转折追问：为什么会这样？东西从哪来？够得着吗？现实里真会这样吗？
3. 能用一句话说清这支片子想表达什么吗？和文件开头写的那句一致吗？
4. 开头几秒抓人吗？最抓眼球的画面在前面吗？
5. 旁人的反应像真人吗？有没有先后？有没有几个人同一秒做同一个动作？
6. 哪些镜头 AI 视频模型容易拍错？重点看：人物交叉、手拿小东西、文字、镜子和倒影、左右不对称的特征、一个镜头里换光、一个人连做三个动作、俯拍看不到脸、配角太多。
每条写：镜头、问题、建议改法。没把握的写"可能"。最后写"通过"或"不通过"。
```

## 2. 首尾帧审核（阶段 4，画之前审文字，画之后审图）

材料：[该镜头的首帧 / 尾帧文字说明或图片]、[设定图]、[该镜头的分镜]、[palette.md]

```
你是审核，只读不改。下面是一个镜头的首帧和尾帧（以及设定图和分镜）。每张图都放大看。
1. 动作要用到的东西，首帧里都有吗？
2. 别人的反应提前摆好了吗（做事的人在前，反应的人在后、脸朝镜头）？
3. 多人有没有摆成同一个姿势？
4. 东西要落到、飘到的地方空出来了吗？人头顶留空了吗？
5. 风向统一吗？
6. 缩到手机大小还看得清主要人物吗？
7. 有没有多余的东西、奇怪的线、多出来的手指？
8. 首尾帧叠起来看，不该变的地方（墙色、家具位置、物体大小）完全一样吗？
9. 和设定图对得上吗（服装、发型、不对称特征在哪一侧）？和配色表对得上吗？
逐条写出问题所在的图、位置和建议改法。最后写"通过"或"不通过"。
```

## 3. 提交前审核（阶段 6，每个镜头交给用户生成之前，必做）

材料：[prompt_master.md]、[后端格式的提示词]、[pack/ 里的全部文件]、[greybox_first.png 和 greybox_last.png（有白膜时）]、[这场戏的机位图 png 和 floorplan.py 输出的画面左右表]、[设定图]、[分镜表中该镜头的一行]、[palette.md]、[前后两个镜头的首尾帧]

```
你是审核，只读不改。这个镜头马上要提交视频生成，要花真钱或者大量时间。
逐项核对，图片要放大看：
1. 提示词的每一句话和图片对得上吗？位置、左右、颜色、人数、道具数量、衣服、表情。
2. 首尾帧的机位、尺寸、背景一致吗？白膜第一帧和最后一帧的构图和首尾帧对得上吗？
3. 和设定图、配色表、前后镜头对得上吗？和机位图（blocking/ 里这场戏的 png 和画面左右表）对得上吗：人物左右、视线方向、前后景？
4. 动作符合现实吗？每个动作的原因写了吗？手放在哪写了吗？
5. 模型可能在哪里出错：同时动作、凭空出现、物体长出脸、走反方向、有歧义的词、数量变化？
6. 后端格式对吗：引用编号和上传顺序一一对应吗？（H3：字段名、顺序、标签前后一致吗？结构化部分是英文吗？时间点在时长范围内吗？）
7. 时长和动作量匹配吗？
最后只写"通过"或"不通过"。不通过就逐条列出要改什么。
```

## 4. 全片复核（阶段 8）

材料：[成片文件路径]

```
这是一支短片的成片。你第一次看，我不告诉你任何结论。
1. 用 ffmpeg 完整解码。每个镜头取多张全分辨率帧；找出切点，切点前后各取 3 帧。
2. 先写你看懂的故事，再列出看不懂的地方。
3. 逐个镜头查：重复的动作、道具数量变化、穿帮、突跳、颜色跳变、脸部变形、文字问题。
4. 明确写出你查不了的东西（动作的流畅感、声音）。
每条写：时间、帧号、问题。分成"硬伤"和"小问题"两类。
最后写"通过"（没有硬伤）或"不通过"。
```
