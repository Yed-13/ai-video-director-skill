# 阶段 6：提示词体系与提交包

出了问题先怀疑提示词，再怀疑模型。成套示例见 `prompt-examples.md`。

## 1. 一支片子里的几种提示词

| 提示词 | 给谁 | 写什么 | 不写什么 | 在哪 |
|---|---|---|---|---|
| 画风句 | 所有图和视频 | 一句固定的画风描述 | 每次换说法 | `styles/` |
| 设定图提示词 | 图像模型 | 人物、场景、道具的外观，中性光 | 剧情、场景光 | `03-style-sheets.md` |
| 首帧提示词 | 图像模型 | 外观、环境、光、构图、这个机位的视野 | 动作过程 | `04-keyframes.md` |
| 视频提示词 | 视频模型 | 变化：动作、顺序、速度、停止状态、运镜、声音 | 图里已经清楚的静态内容；图里没有的东西 | 本文件 |
| 白膜任务书 | 写代码的 agent | 机位、走位、时间线 | 画风 | `05-greybox.md` |
| 审核任务书 | 审核 agent | 材料和检查项 | 你的结论 | `review-briefs.md` |
| 提交任务书 | 操作浏览器的 agent | 上传顺序、参数、停下的条件 | 没齐的素材 | `submit-codex.md` |

**首帧提示词和视频提示词是两回事。** 首帧决定"长什么样"，视频提示词只说"怎么变"。视频提示词里：

- 静态内容只写容易出错、必须保持的几样；写之前对着图核对。
- **图里没有的东西一律不写**，写了就会凭空出现。"画面里看不到 X"也不写：提到就会画。
- 文生视频（没有首帧）才需要把画面本身写全：主体 + 环境和位置 + 动作 + 光 + 景别机位 + 一种运镜 + 少量连续性要求。

## 2. 先短后长

| 档 | 适合 | 长度 | 写法 |
|---|---|---|---|
| 最短有效版 | 单镜、无台词、动作简单 | 一两句到一百多字 | 谁怎么动、停在哪、机位、必须保持的一两样 |
| 带节奏版 | 单镜、有先后顺序或一句台词 | 两三百字 | 加时长、开始—变化—停止、运镜起止 |
| 按场母版 | 一场戏 2–4 个镜头、有表演和台词 | 每场约 3000–3700 字（即梦上限 15000） | 第 4 节 |

- 单镜先试最短版，结果明确缺什么，再补对应的那一条约束。一轮只改一两个变量，记进 `log.md` 的版本表（`gacha.md`）。
- 按场母版里每个镜头的"怎么做"写满，不为省字数删；字数花在速度、停顿、手、视线、怎么切上，不花在重复静态描述上。

## 3. 官方结构（Seedance 2.5）

官方提示词指南建议四块，母版与之对应：

| 官方 | 写什么 | 母版里的位置 |
|---|---|---|
| 素材引用 | 按上传顺序写明每个素材的用途，并和文字里的角色绑定 | 【参考】 |
| 一句话概述 | 主体 + 地点 + 事件 + 风格 + 运镜 | 【这场戏】【镜头总览】 |
| 详细剧情 | 按镜头序列（Shot 1 / 镜头一）或时间轴（0-3 秒）写 | 【镜头 N】 |
| 补充说明 | 全程不变的：机位规则、环境、声音、氛围 | 【光】【画风】【人物】【约束】 |

官方另外几条：负面约束只用在字幕和音频上（"不加字幕""没有背景音乐"），其余用正面描述；冷僻术语写成"术语 + 解释"；情绪词过激会出怪相（眼睛发光），换成具体动作。

## 4. 母版

每段先写中文母版 `prompt_master.md`（给你和审核 agent 核对），再翻译成后端格式（`backends/`）。

### 单镜母版（一镜到底，首尾帧 + 白膜）

```
【参考】@图片1 = 首帧，@图片2 = 尾帧，@图片3 = 某某身份板（只参考人物外观），@图片4 = 场景图（只放一张），@视频1 = 白膜（只参考运镜、走位和时间），@音频1 = 某某的音色参考。
【站位】谁在画面左 / 右（照机位图的"画面左右"表），摄影机在轴线哪一侧，道具在谁手里。
【镜头】整段 X 秒，<景别>，<机位：位置、高度、焦段>，<一种运镜：类型 + 幅度 + 速度 + 停在哪；不动写"固定机位，不推不拉不摇，不切镜">。
【动作】开头画面和首帧一样。<按先后写：谁做什么、怎么做、手在哪、往画面哪侧、停在什么状态>。最后停住，画面和尾帧一样。
【声音】台词（见第 6 节）；音效只写看得见声源的；没有背景音乐，没有字幕。没有台词写"人物闭着嘴"。
【光】<光色表里这场戏的光色句，原样复制>
【画风】<brief.md 的固定画风句>
【人物】<人物卡原样复制；只留容易出错的特征>
【约束】只有首帧里的这些人和东西；脸和身形不变；道具不换手、不消失。
```

### 按场母版（同一场景同一时间的 2–4 个镜头，一次生成）

```
【参考】每个 @ 写清只参考什么、不参考什么。
【前情】【这场戏】【她此刻】（潜台词；见 acting-voice.md）
【镜头总览】整场 N 秒，几个镜头，各约几秒，硬切。
【开场】接着上一场哪一刻：姿势、光、环境声连续，不从静止和静音开始。
【镜头一｜约 a–b 秒】
  机位：位置、高度、焦段、动不动、焦点在哪。
  画面：只写这个机位看得见的（照 VIEW 清单，见 room-layout.md）。
  表演：一个主要动作，写怎么做。
  声音：这一镜里的台词和动作声。
  怎么切出：在哪个动作的半途切，动作跨过切点连续完成。
【镜头二｜约 b–c 秒】……
【结尾交接】停在什么画面、停几秒；不淡出，不加转场（需要画面内转场时除外，见 `09-transitions.md`）。
【台词与声音】同一段发声描述 + 每句的语速和停顿；环境声全程连续，切镜时不断。
【光】【画风】【人物】【动作幅度】【文字】【约束】
```

- 模型会自己调切点，常比写的早 0.5–2 秒；镜头时间写"约"。
- 时长逐镜加总：台词约每 10 字 2 秒，动作按日常速度，最后留 1.5–2 秒交接停顿。
- 【文字】一栏：`画面里的印刷字和手写字都在景深外或角度太斜，只是模糊的笔画影子`；要读得清的字后期贴。

### 接续上一场

上一场**正片**的最后 3–4 秒做成 @视频1（`scene.py tail`），【参考】里写 `本场从 @视频1 的最后一帧接着拍，@视频1 只用来接续，不是要修改的素材`；第一个镜头沿用 @视频1 的机位，1–2 秒后再切。时间跳转（上午到傍晚）不要硬接：用同构图换光的匹配剪辑、有人动手造成的变化，或另生成 1–2 秒首尾帧过渡。要在画面里藏接缝（遮挡、甩镜、匹配剪辑等）、取尾帧、检查接缝，见 `09-transitions.md`。

## 5. 时间怎么标

- **镜头和动作**可以标时间：Seedance 2.5 认整数秒的区间（`0-3 秒：`）、时间点（"第 5 秒时"）和相对时间（"3 秒后"）；区间首尾相接，不留空。2.0 只认"镜头 N"，不认时间戳。
- 一个区间里内容太少，模型会自己加戏；太多，会多切镜或漏情节。高频动作不用时间戳控制。
- **对白不标秒**，只写顺序和停顿（`acting-voice.md`）。
- H3 写 `[Shot 2] At 00:02.000, the camera cuts to ...`。

## 6. 台词与声音

| 类型 | 母版 | H3 |
|---|---|---|
| 当面说 | 羊羊说（平淡）：「其实，我是诗仙。」 | `<Subject 1> (S1) says calmly, <d>[Chinese] 其实，我是诗仙。</d>` |
| 内心独白 | 老师内心独白：「……」，嘴唇始终闭着 | `(S2) says in an off-screen voiceover: <d>[Chinese] ……</d> while his lips remain completely closed.` |
| 画外音 | 羊羊画外音：「……」 | `(S1) says in an off-screen voiceover: <d>[Chinese] ……</d>` |

- 三种不分开，模型会让角色张嘴念心里话。
- 台词只写一遍，格式固定为"角色（情绪）：内容"；台词后面再重复一遍或另加语气说明，容易触发字幕。参考视频不能带字幕，会被继承。
- 同一角色的声音：先用固定的声音描述；第一段满意后剪出 3–10 秒干净人声当音色参考（"@音频1 是羊羊的音色"）；再不行，先配好音再用音频驱动对口型。只用自己的或有授权的声音。
- 发声一致、口型回避、表演写法见 `acting-voice.md`。

## 7. 常见错误对照

| 模型的错 | 写法 |
|---|---|
| 一群人同时做同一个动作 | 写先后："爸爸先……过一两秒奶奶才……"；首帧不摆同一姿势 |
| 该由外力做的事人自己动手 | 写原因，加"两只手始终没碰到邮包" |
| 云、月亮、植物长出脸 | 写"蓬松的灰白积云，只有棉絮状纹理"，只写怎么移动 |
| 走反方向 | 按画面写"朝画面左侧走"，和机位图的运动轴线一致 |
| 正反打左右对调、视线对不上 | 抄机位图位置："A 在画面左 35%，视线看向画面右侧镜头外" |
| 过肩镜头前景的人转身、两人长相混 | "前景是 B 的右肩和后脑，虚化，始终背对镜头"；不稳就改内反拍 |
| 一句话两种理解 | 写具体位置（"左上角石头房子的窗口里"） |
| 数量变了 | 写数量："只有一封黄色信封" |
| 写"不要……"没用 | 改正面说法；或者这个镜头里不放这个道具 |
| 东西凭空出现 / 瞬移 / 状态突变 | 只用首帧里有的东西；状态变化写出是谁做了什么 |
| 雨、帽子、纹身消失 | 首尾帧都画上，人物段再写一次 |
| 动作太多就乱 | 每个镜头一个主要动作 |
| 一只手连做翻纸、拿笔、拔笔帽 | 拆成两只手或两个镜头；或首帧里笔已经在手上 |
| 同一个人一会儿悄悄话一会儿正常 | 整场一段发声描述，去掉耳语、气声一类词 |
| 对白被填进耳语、台词提前说完 | 去掉对白的逐秒时间戳 |
| 构图参考图的姿势被照搬 | 用途写"只参考机位和构图，人物动作以文字为准" |
| 签名、手写字变成假英文 | 写成虚焦的笔画影子，后期贴真实字 |
| 时间不准、推镜不明显 | 时间以白膜为准，多留余量后期变速；推镜不够后期补 |
| 嘴自己动 | "闭着嘴在听"；还动就后期修 |
| 出现字幕 | 结尾写"不加字幕"；检查台词有没有重复写 |

各风格特有的失败在 `styles/` 对应文件里。

## 8. 提交包

1. 素材放进镜头文件夹：`first.png`、`last.png`、`greybox.mp4`、`ref_*`。参考素材按文件名排序、排在首尾帧之后，用数字前缀控制顺序（`ref_1_羊羊身份板.png`、`ref_2_书院正打.png`、`ref_3_羊羊声音.mp3`），【参考】编号要和 `pack/README.txt` 一致。多角色按首次出场顺序排。
2. 提示词存为 `prompt_jimeng.txt`、`prompt_ark.txt`（方舟；没有时沿用即梦的）或 `prompt_h3.txt`。
3. `python3 scripts/pack.py build shots/s03 --backend jimeng --duration 6 --model "<模型版本>"`；默认按 Seedance 2.5 的限制校验（最长 30 秒），用 2.0 加 `--seedance 2.0`；出样片加 `--draft --takes 3`。脚本检查素材和后端限制、提示词长度，生成编号文件和 `README.txt`。
4. 另开子 agent 做提交前审核（`review-briefs.md` 第 3 份），不通过就改了重审。改完的句子至少自己 grep 一遍，括号和引号要闭合。
5. 告诉用户：包在哪、预计积分或费用、先出哪几段样片。走方舟 API 时，用户同意报价后由你提交；交给别的 agent 提交见 `submit-codex.md`。

## 9. 生成策略

抽样片、选片、升正片、接续的顺序见 `gacha.md`。

- 主要角色先各自单独出一段，确认长相和声音，再放进多人段落。
- 一段只喂一张场景图；对话戏可以加一张站位大全景。
- 本地 H3：seed 相同结果几乎相同，抽卡换 seed，微调提示词保持 seed，seed 记进 `log.md`。
