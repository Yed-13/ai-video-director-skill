# 阶段 6：视频提示词与提交包

出了问题先怀疑提示词，再怀疑模型。

## 一段只讲一件事

每次生成（5–15 秒）只处理一个动作、一次情绪转折或一句关键台词；不同场景、不同时间分开生成。动作接上一段的结尾，不重复上一段做完的动作。一段可以是一镜到底（首尾帧 + 白膜），也可以是 2–4 个镜头的多镜生成段（对话戏，见 `02-shotlist.md`）。

## 母版

每段先写中文母版 `prompt_master.md`（给你和审核 agent 核对），再翻译成后端格式（`backends/`）。

```
【参考】@图片1 = 首帧，@图片2 = 尾帧，@图片3 = 某某身份板，@图片4 = 场景图（只放一张），@视频1 = 白膜（只参考运镜、走位和时间），@音频1 = 某某的声音参考。
【站位】谁在画面左 / 右（照机位图的"画面左右"表），门在哪边，摄影机在轴线哪一侧，道具在谁手里、朝哪边。
【画风】<brief.md 的固定画风句>，画风、颜色、人物设计与首尾帧完全一致。
【镜头】整段 X 秒，<景别>，<机位>，<运镜：类型 + 幅度 + 速度；不动写"固定机位，不推不拉不摇，不切镜">。说台词时尽量固定。
【光色】<光色表里这场戏的光色句，原样复制>
【人物】<人物卡原样复制：长相、衣服、固定道具、不对称特征在哪侧；说话的角色加一句固定的声音描述>
【逐秒】
0–0.2 秒：画面静止，和首帧一模一样。
<谁做什么，表情怎么变，手放在哪、不能碰什么，往画面哪侧移动>
最后 0.3 秒：所有人停住，画面和尾帧一模一样。
【声音】台词一字不改，分三种写法（见下）；音效只写看得见声源的。不要背景音乐和字幕。没有台词写"人物不说话"。
【约束】始终只有首帧里的这些人和东西，脸和身形不变，道具不换手、不消失，人物不瞬移；没有文字、字幕、水印。
```

多镜生成段把【逐秒】换成 `镜头 1（0–2 秒）：近景……；镜头 2（2–4 秒，切到）：全景……`；H3 写 `[Shot 2] At 00:02.000, the camera cuts to ...`。

## 台词与声音

| 类型 | 母版 | H3 |
|---|---|---|
| 当面说 | 羊羊说：「其实，我是诗仙。」（平淡） | `<Subject 1> (S1) says calmly, <d>[Chinese] 其实，我是诗仙。</d>` |
| 内心独白 | 老师内心独白：「……」，嘴唇始终闭着 | `(S2) says in an off-screen voiceover: <d>[Chinese] ……</d> while his lips remain completely closed.` |
| 画外音 | 羊羊画外音：「……」 | `(S1) says in an off-screen voiceover: <d>[Chinese] ……</d>` |

- 三种不分开，模型会让角色张嘴念心里话。
- 每句写语气。5 秒最多一两句（约每 10 字 2 秒），否则口型对不上。
- 长台词中途要切到听的人；生成时做不到就后期盖反应镜头（`08-post.md`）。

同一角色每段同一个声音，从简单到进阶：
1. 固定的声音描述（"二十岁出头的男声，清亮，语速平稳"），每段原样复制。
2. 第一段满意后剪出 3–10 秒干净人声（有音乐先用 Demucs 分离），后面每段作为音频参考："@音频1 是羊羊的声音"；H3 写 `<Audio 1> is the voice-timbre reference for <Subject 1> (S1).`（音频要和图片或视频一起传）。
3. 先用同一音色配好台词，再用音频驱动 / 数字人模式对口型（声音一致，表演受限）。

只用自己的或有授权的声音，不克隆明星或他人。

## 常见错误对照

| 模型的错 | 写法 |
|---|---|
| 一群人同时做同一个动作 | 写先后："爸爸先……过一两秒奶奶才……"；首帧不摆同一姿势 |
| 该由外力做的事人自己动手 | 写原因，加"两只手始终没碰到邮包" |
| 云、月亮、植物长出脸 | 写"蓬松的灰白积云，只有棉絮状纹理"，只写怎么移动 |
| 走反方向 | 按画面写"朝画面左侧走"，和机位图的运动轴线一致 |
| 正反打左右对调、视线对不上 | 抄机位图位置："A 在画面左 35%，视线看向画面右侧镜头外" |
| 过肩镜头前景的人转身、两人长相混 | "前景是 B 的右肩和后脑，虚化，始终背对镜头"；不稳就改内反拍 |
| 一句话两种理解 | 写具体位置（"左上角石头房子的窗口里"），补"驾驶座始终是空的" |
| 数量变了 | 写数量："只有一封黄色信封" |
| 写"不要……"没用 | 改正面说法；或者有动作的镜头里不放这个道具（壶总会倒水） |
| 东西凭空出现 / 瞬移 | 只用首帧里有的东西；写出运动过程 |
| 雨、帽子、纹身消失 | 首尾帧都画上，人物段再写一次 |
| 闪电太写实 | "云层里闪一下白光"，后期剪开头 |
| 动作太多就乱 | 每个镜头一两个主要动作 |
| 时间不准、推镜不明显 | 时间以白膜为准，多留余量后期变速；推镜不够后期补 |
| 嘴自己动 | "人物不说话"；还动就后期修 |

## 提交包

1. 素材放进镜头文件夹：`first.png`、`last.png`、`greybox.mp4`、`ref_*`。参考素材按文件名排序、排在首尾帧之后，用数字前缀控制顺序（`ref_1_羊羊身份板.png`、`ref_2_书院正打.png`、`ref_3_羊羊声音.mp3`），【参考】编号要和 `pack/README.txt` 一致。
2. 提示词存为 `prompt_jimeng.txt` 或 `prompt_h3.txt`。
3. `python3 scripts/pack.py build shots/s03 --backend jimeng --duration 6 --model "<模型版本>"`：检查素材和后端限制，生成编号文件和 `README.txt`（上传顺序、参数、提示词）。
4. 另开子 agent 做提交前审核（`review-briefs.md` 第 3 份），不通过就改了重审。
5. 告诉用户：包在哪、预计积分或耗时、建议先生成哪几段。

## 生成策略（写进给用户的说明）

- 不另拍测试片。每段先用最短时长（或本地 H3 的 4 步加速、低分辨率）出一版，满意再出完整版；选中的段落再用完整步数或超分精修。
- 新方法（比如第一次用白膜）先拿最难的一两段试。
- 主要角色先各自单独试一段，确认长相和声音，再放进多人段落。
- 一段只喂一张场景图；对话戏可以加一张站位大全景。
- seed 相同结果几乎相同：抽卡换 seed，微调提示词保持 seed。seed 记进 `log.md`。
- 即梦：普通镜头用便宜的模型版本就够。自带的声音要听过才用。
