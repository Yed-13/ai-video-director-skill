# 阶段 6：视频提示词与提交包

生成出了问题，先怀疑提示词，再怀疑模型。提示词写得越细，抽卡率越低。

## 一段只讲一件事

每次生成（一段，5–15 秒）只处理**一个动作、一次情绪转折或一句关键台词**。不同场景、不同时间必须分开生成。动作要**接上一段的结尾**：上一段已经站起来了，这一段就从站着开始，不重复上一段做完的动作。

一段可以是一个一镜到底的镜头（用首尾帧 + 白膜控制），也可以是 2–4 个镜头合成的"生成段"（对话戏常用，见 `02-shotlist.md`）。

## 通用母版（和后端无关）

每段先写一份中文母版 `prompt_master.md`，再按后端翻译成即梦或 H3 的格式（见 `backends/`）。母版是你和审核 agent 核对用的，不直接提交。

```
【参考】@图片1 = 首帧，@图片2 = 尾帧，@图片3 = 某某的身份板，@图片4 = 场景图（只放一张），@视频1 = 白膜（只参考运镜、走位和时间），@音频1 = 某某的声音参考……每个素材都写明用途。
【站位】谁在画面左、谁在右（照机位图的"画面左右"表），门在哪边，摄影机在轴线哪一侧，关键道具在谁手里、朝哪个方向。
【画风】<brief.md 里那句固定画风描述>。整段的画风、颜色、人物设计与首帧和尾帧完全一致。
【镜头】整段 X 秒，<景别>，<机位>，<运镜：类型 + 幅度 + 速度；不动就写"固定机位，不推不拉不摇，不切镜">。说台词时镜头尽量固定。
【光色】<原样复制光色表里这场戏的光色句>（见 `light-color.md`），和首帧一致。
【人物】<从人物卡原样复制：长相、衣服、固定道具、不对称特征在哪一侧；说话的角色再加一句固定的声音描述>
【逐秒】
0–0.2 秒：画面静止，和首帧一模一样。
<每一段：谁做什么，表情怎么变，手放在哪、不能碰什么，往画面哪一侧移动>
最后 0.3 秒：所有人完全停住，画面和尾帧一模一样。
【声音】台词一字不改，按三种写法区分（见下文）；音效只写看得见声源的声音。不要背景音乐，不要字幕。没有台词就写"人物不说话"。
【约束】画面里始终只有首帧里的这些人和这些东西，脸和身形全程不变，道具不换手、不消失，人物不瞬移。画面干净，没有文字、字幕和水印。
```

多镜头的生成段，把【逐秒】换成按镜头写：`镜头 1（0–2 秒）：近景……；镜头 2（2–4 秒，切到）：全景……`。H3 写成 `[Shot 1] ... [Shot 2] At 00:02.000, the camera cuts to ...`。

## 台词与声音

**三种声音必须分开写**，否则模型会让角色张着嘴把心里话念出来：

| 类型 | 母版写法 | H3 写法 |
|---|---|---|
| 当面开口 | 羊羊说：「其实，我是诗仙。」（平淡） | `<Subject 1> (S1) says calmly, <d>[Chinese] 其实，我是诗仙。</d>` |
| 内心独白 | 老师内心独白：「……」，嘴唇始终闭着 | `... (S2) says in an off-screen voiceover: <d>[Chinese] ……</d> while his lips remain completely closed.` |
| 画外音（人不在画面里） | 羊羊画外音：「……」 | `(S1) says in an off-screen voiceover: <d>[Chinese] ……</d>` |

- **一段别塞太多台词**：5 秒的段落最多一两句，大约每 10 个字 2 秒。台词太长、语气没写、段落太短，口型都容易对不上。
- **每句写清语气**（平淡、哽咽、冷笑）。
- **长台词别一直对着说话的人**：中途切到听的人，台词不断（生成时做不到，就在后期补反应镜头，见 `08-post.md`）。

### 让同一个角色每段都是同一个声音

从简单到进阶：

1. **声音描述写死**：给每个说话的角色写一句固定描述（"二十岁出头的男声，清亮，语速平稳，带一点不在乎"），每段原样复制，不换说法。
2. **用第一段的声音当参考**：第一段满意后，剪出这个角色说话的 3–10 秒（干净，没有音乐；有音乐就先用 Demucs 分离人声），后面每段都作为音频参考传进去："@音频1 是羊羊的声音"。H3 Ref2VA 写成 `<Audio 1> is the voice-timbre reference for <Subject 1> (S1).`，音频不能单独使用，要和图片或视频一起传。
3. **先配音再对口型**：用同一个音色先把台词配好，再用后端的音频驱动 / 数字人模式按这条声音生成口型。声音完全一致，但表演会受限。

只用自己的声音或有授权的声音做参考，不要克隆明星或他人的声音。

## 模型常见错误和对应写法

写完母版，对照这张表检查一遍：

| 模型常犯的错 | 怎么写 |
|---|---|
| 一群人同时做同一个动作 | 写出先后顺序："爸爸先……过一两秒奶奶才……小女孩最后……"；首帧里也不要摆成同一个姿势 |
| 本该由风或外力完成的事，人自己动手了 | 写清楚原因，再加一句"他的两只手始终没有碰到邮包" |
| 云、月亮、植物长出眼睛和嘴 | 不写"卡通云"，写"蓬松的灰白积云，只有棉絮状的纹理和阴影"；只描述它怎么移动 |
| 人往反方向走 | 方向按画面写："朝画面左侧走，经过左边的店门"；方向要和机位图里的运动轴线一致 |
| 正反打时两人左右对调、视线对不上 | 从机位图的"画面左右"表抄位置："A 在画面左侧 35% 处，视线看向画面右侧镜头外" |
| 过肩镜头里前景的人转过身来，或两人长相混在一起 | 写死："前景是 B 的右肩和后脑，虚化，始终背对镜头不转身"；拿不准就改用内反拍单人镜头 |
| 一句话有两种理解（"窗户后面的老人"结果车里冒出人） | 写得更具体："左上角石头房子的窗口里"，再补一句"驾驶座始终是空的" |
| 东西的数量变了 | 直接写出数量："只有一封黄色信封" |
| 写"不要……"没用（写了"壶嘴不出水"还是出水） | 改成正面的说法："画面里始终只有首帧里这几个人"；或者干脆不让这个道具出现在有动作的镜头里 |
| 模型自己联想道具用途（壶总是会倒水） | 有动作的镜头里不放这个道具 |
| 东西凭空出现 | 只用首帧里已经有的东西 |
| 东西突然飞走或瞬移 | 把运动过程写出来："顺着后脑勺往后滑，被他接住，扣回头上" |
| 雨、帽子、纹身拍着拍着就没了 | 首帧和尾帧都画上，人物段里再写一次 |
| 闪电太写实 | 写"云层里闪一下白光"，后期再把开头剪掉 |
| 一个镜头动作太多就乱 | 每个镜头只写一两个主要动作 |
| 动作时间和写的不一致 | 写的时间只算大概；多留余量，后期用剪辑和变速对上节拍。有白膜的话，时间以白膜为准 |
| 推镜没有写的那么明显 | 用白膜给出轨迹；或者后期用代码再推一点 |
| 嘴自己在动 | 写"人物不说话"；还动就后期修 |

## 提交包

母版写完、翻译成后端格式后：

1. 把素材按约定命名放进镜头文件夹：`first.png`、`last.png`、`greybox.mp4`，以及可选的 `ref_*.png` / `ref_*.mp3`。参考素材按文件名排序编号（排在首帧、尾帧之后），所以用数字前缀控制顺序：`ref_1_羊羊身份板.png`、`ref_2_书院正打.png`、`ref_3_声音羊羊.mp3`，【参考】里的编号要和 `pack/README.txt` 列出的一致。
2. 后端格式的提示词存为 `prompt_jimeng.txt` 或 `prompt_h3.txt`。
3. 运行 `python3 scripts/pack.py build shots/s03 --backend jimeng --duration 6 --model "<模型版本>"`。脚本会：
   - 检查文件数量、格式、时长、首尾帧尺寸是否一致、画幅比例；
   - 按上传顺序把文件复制成 `pack/01_首帧.png`、`pack/02_尾帧.png`、`pack/03_白膜.mp4`……；
   - 生成 `pack/README.txt`：上传顺序、要选的参数、要粘贴的提示词。
4. **另开子 agent 做提交前审核**（`review-briefs.md` 里的"提交前审核"）。不通过就改，改完重新审。
5. 审核通过后告诉用户：包在哪、预计花多少积分或要跑多久、建议先生成哪几个镜头。

## 生成策略（写进给用户的说明里）

- 不单独拍测试片，直接拍第一个正式镜头，能用就算赚到。
- 新方法（比如第一次用白膜）先拿一两个最难的镜头试，行得通再全部提交。
- 用 720p（即梦）或 768p（H3）生成，后期再放大到 1080p。
- 即梦选模型时：不是特别考验模型能力的镜头，用便宜的版本就够了。
- 视频自带的声音要听过才能用；不确定的话，后期统一重新配音效。
- **先短后长**：新段落先生成 4–5 秒预览，满意了再出完整时长。
- **角色先单独试**：每个主要角色先单独跑一段，确认长相和声音对了，再把几个人放进同一段。
- **一段只喂一张场景图**：几张场景图一起喂，模型不知道用哪张，场景会乱。对话戏可以额外喂一张站位大全景，比文字描述站位更管用。
- **seed**：同样的素材 + 提示词 + seed，结果几乎一样。想抽卡就换 seed；只想微调提示词，就保持 seed 不变，这样才看得出改动的效果。每次生成都把 seed 记进 `log.md`。
- **质量分档**（本地 H3）：抽卡和预览用低分辨率或 4 步加速；选中的镜头再用完整步数生成，或者做一次超分 / 二次采样精修。
